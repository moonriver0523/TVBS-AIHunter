# A33 S4 稿單提案生成器（唯讀、每天一次） — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:test-driven-development。前置：12-A34（CTV 候選 json）、13-A10P1a（登記簿 canonical）。D16 裁決：記者名單由使用者之後提供，**分派欄先只填角色**。

**Goal:** 兩段式：①`scripts/s2_rundown_propose.py`（機械評分，產 `{MMDD}-稿單候選.json`）②`scripts/s2_rundown_prompt.md`（獨立 agent 讀候選 json、寫題目／角度／形式，產 `{MMDD}-稿單提案.txt`，格式同 `common/11` 稿單）。全程**唯讀**狀態檔。

**Architecture（不變式，繼承 0819／0825 評估）:** 不寫 `category`、不開中主題／機動 T、不搶 `.s2-scan.lock`、獨立檔案在 `自動掃帶系統/_稿單提案/`。評分只用既有欄位：`alerts`／🔴🟡🔖🟤（從 render 成品認，同 `s2_render_html.collect`）、`tc`、`source` 多樣性、`fields.bite`、登記簿 canonical（跨大分類聚合）、A34 CTV 候選。

**Tech Stack:** Python；prompt 檔比照 `s2_reclass_prompt.md`。

## Global Constraints

- 每天跑一次，建議 07:00 輪收工後（人工下令或 session cron，**不進 `s2_scan.ps1`**）。
- 提案題數上限 12（使用者可改常數）。
- ⛔ prompt 明文：不准呼叫任何 `s2_state.py` 寫入子指令；只能讀候選 json 與（必要時）`get --id` 單則。
