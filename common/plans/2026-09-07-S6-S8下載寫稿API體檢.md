## 0. 一句話結論

- **S6 下載**：AP／RT／NS 的 API 化在 2026-08-03／08-09 已做到能做的極限（定位＋文稿三站全 API，影片只有 AP 能 API 直連；RT 真點按鈕、NS Signiant 都是查明後判定做不到）。本次沒有新的可攻點，只修文件漂移。**ENEX／ABC 下載流程本次已補寫並實測到直鏈**。

- **S8 寫稿本體**（`common/06` 鐵則～輸出、`cnn/01` 步驟 5–6）**沒有 API 可串**：那是 LLM 寫作＋`validate_sot.py` 確定性檢查，優化空間在規則不在串接。本檔不碰。

## 3. ENEX／ABC 實測記錄（供日後對照）

**ENEX**
- ES `_search` 不加 `_source` 白名單，`_source` 全欄位：`status／published／thumb／editorsChoice／title／subject／description／location／region／country／language／partner／start／category／lastModified／publishedDate／pictureDate／creationDate／newslinkId／tags／videoLowRes／videoLowResCdn／editStatus／editStatusSort／contributor／filename／ntscTranscodingStatus／sortDate`（＋5 個 `*Suggest`）。**沒有任何高解析度網址欄位**，全解析度只能從 `/download/{id}` 拿。
- `/download/929921` → `302` → `https://enexfeed.s3.eu-west-1.amazonaws.com/{filename}?X-Amz-Algorithm=AWS4-HMAC-SHA256&…&X-Amz-Expires=600&X-Amz-Signature=…&check_logged_in=1`。帶 `check_logged_in=1` 打：`403 SignatureDoesNotMatch`；拿掉：`206 Partial Content`、`bytes 0-0/522565697`、`video/mp4`。`HEAD` 一律 403（簽章綁 GET）。
- 頁內 `fetch('/download/…')` → `TypeError: Failed to fetch`（S3 無 CORS）。

**ABC**
- `NewsSearch`（不加 `getCSV`）50 列：`detailId`／Story Number／slug 對映正常（`641866589` ↔ `090726016` ↔ `Sept11FinalTowerVOSOT`）。
- Detail 頁 35KB：`Script`／`Synopsis`／`Length`／`Destination: TVBS News`／`Delivery Status: Awaiting Approval`；動作只有 `a[href^="/Delivery/ApproveNews/"]`（`title="Approve this news story for download"`）與 `form[action="/Delivery/UpdateDeliveries"]`（hidden `UpdateActionFlag`／`deliveryIds`）。
- `NewsDeliveries?pageSize=200`：20 列（19 `Awaiting Approval`、1 `Ready For Download`）。Ready 那列多出 `Download local delivery` → `/Delivery/Download/{GUID}?c=&mpid=&did=&d=` 與 `Acknowledge media delivery` → `/Delivery/Acknowledge/{GUID}`。
- `/Delivery/Download/…` 頁內 fetch：`redirect:'manual'` 回 `opaqueredirect`；`follow` 拋 `Failed to fetch`，console 顯示轉址目的地 `https://s3.amazonaws.com/fs2.extremereach.com/media/50162/102968/090626071.mp4?AWSAccessKeyId=…&Expires=1788935834&response-content-disposition=attachment%3BfileName%3D090626071.mp4&Signature=…`。
- ⛔ 未做：核准任何素材、實際下載、Acknowledge。

**NS**
- `term: null, size: 3` → `WE-003MO／PY-01MO／WE-002MO`；`term: "WE-003MO", size: 5` → 恰 1 則。回應每則頂層鍵：`owner／alternateIds／keywords／videoTypes／footageType／description／reporter／title／content／duration／relevancyDate／createdDate／provider／modifiedDate／categories／id／embargo／contentType／videoPreviewUrl／thumbnailUrl／downloaded／relevance`。
