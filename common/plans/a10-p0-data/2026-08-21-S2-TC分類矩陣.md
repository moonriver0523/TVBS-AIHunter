# S2 T/C 分類矩陣（取代線性大分類裁決）

- 2026-08-21 重寫。`2026-08-21-S2-P0關鍵詞覆核與裁決建議.md` 裡 **D-a／D-b／D-c／D-h 的「一則塞一格／題材優先於地緣／C 不必開格」作廢**，與矩陣牴觸。
- 權威是 **T×C 標籤**，不是大分類樣板。樣板只剩顯示預設排序（可另裁），不再是歸屬規則。
- 本檔只定字典與對照；未授權改 `s2_state`／13。

## 0. 矩陣規則（不可退回線性）

1. 每個**小分題**至少 1 個 T、1 個 C；可複選。
2. T 與 C **正交**：社會×美國、財經×美國、天災×日本 可以同時成立。禁止再問「該進社會還是美國」。
3. 中分題＝子項 T/C **聯集**（規則式）。素材繼承小分題。
4. 舊大分類名稱若出現在畫面，只是篩選預設或排序，**不是**第三套權威。

## 1. T 封閉字典（議題）

固定 9 個。新增固定項只能你明示。

| T | 收什麼 | 不收 |
|---|---|---|
| 戰爭 | 熱戰、停火、前線、軍援武器 | 純軍售財報→財經；純國內兵役立法→政治 |
| 天災天氣 | 颱風、地震、野火、熱浪、洪旱、火山 | 人為火災／工安→社會 |
| 政治 | 選舉、政府、國會、外交、領導人行程 | 政策若主軸是市場／關稅數字→另加財經 |
| 社會 | 治安、刑案、移民、急難、公衛、事故 | 戰場死傷→戰爭；天災死傷→天災天氣（可複選社會若焦點是救援） |
| 財經 | 股市、貿易、關稅數字、企業、能源價 | 純川普演說無市場軸→政治 |
| 科技 | 產業／產品／科學 | 股價→另加財經 |
| 娛樂 | 影音、明星、體育以外的娛樂產業 | 運動賽事→體育 |
| 體育 | 賽事、聯盟、選手 | 球星刑案主軸→社會（可複選體育） |
| 話題 | 軟性、文化、節慶；以及沒有其他固定 T 可掛的收容。可與其他 T 複選當配菜 | **禁止只掛話題收硬新聞**（戰場／選舉／刑案／天災必須掛戰爭／政治／社會／天災天氣） |

**機動 T**（不進固定表）：當日大事，如熊本地震、白海豚颱風。**只有你下令才開**，AI 不得自行新增。開的時候寫一句收什麼；必再掛一個固定 T；只併不改名；冷卻後退休。

歷史依據：人工幾乎每天都有社會／體育／話題／財經／天氣／科技；娛樂不是每天開格，但矩陣裡仍要有 T＝娛樂（AI 已日日用）。戰爭不必再開「烏俄格」當 T——烏俄是 C。

- 肯亞／哥倫比亞等：進其他地區
