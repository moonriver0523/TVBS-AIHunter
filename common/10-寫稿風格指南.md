# 寫稿風格指南（人味層）

**定位**：本文件是「風格參照層」，合成自 [`../style-corpus/`](../style-corpus/README.md) 的三份分析（[A 統計](../style-corpus/analysis_A_report.md)／[B1 質性](../style-corpus/analysis_B_fable.md)／[B2 增補](../style-corpus/analysis_B2_fable.md)，共讀 100 篇許岱軒親筆完成稿）。目標：讓自動寫稿（CTV／SOT）的產出更接近使用者本人的聲音。

**優先序**：本指南**不覆蓋**既有格式規則（`P-001`~`P-021`、字數上限、五行 SB、驗證器檢查）。兩者衝突時以格式規則為準，衝突點集中列在文末「待裁定張力」，由使用者裁決後才調整。

**使用方式**：寫稿代理起稿前讀本指南；交付前跑文末「生成檢核表」自查。原句證據都在 B1/B2 報告裡，本文只留規則與模板，不重複引文。

---

## 0. 語體判定（動筆前先選一種，禁止混排）

| 語體 | 特徵 | 適用 |
|---|---|---|
| **SOT／CTV 完成稿** | 稿頭帶標點＋正文斷行＋SB/NS 標記 | 預設 |
| **快訊 BS** | 「國際最新消息，…」開場，150–250 字一段式，無 SB | 突發快訊 |
| **連線口播** | 無標點短行，「好的主播」開場，「以上是為您掌握的最新情形」收尾，允許重複關鍵資訊 | 連線 |
| **長篇專題** | 見第 9 節，另一套結構 | 9000 字級專題 |

## 1. 稿頭（開場）

句序固定：`規模事實（含 1–2 個數字）→ 轉折詞 → 鉤子（放最後一句）`。四型擇一：

- **A 數字衝擊＋反常個案**（災難稿主力）：數字先砸，再接一個「唯獨／竟然」的個案。
- **B 雙場景對照**：兩個畫面並置，靠「同一時間／而／不過」硬接。
- **C 事件＋判斷語收尾**（政治外交主力）：末句用判斷語庫「似乎是…／顯見…／恐怕…／等於是…／意味著…」，**每篇最多一句**，不疊加。
- **D 觀眾利益切入**（民生／旅遊／消費）：第一句直接向觀眾示警或報好康，允許驚嘆號。

規則：稿頭不用問句（設問留給正文）；不出現素材編號、引語全文；保留正常中文句讀（`P-014`）。**鉤子優先於字數（裁定③）**：A 型稿頭為保末句鉤子可寫到 180 字、接受 WARN；確實過長時優先精簡中段事實，絕不砍鉤子。

**變體（每篇 ≤1 次，限反差/趣聞/體育）**：諺語翻轉開場——`國民級慣用語 →「這句話不適用／都不如／還真不是」→ 主角`；若用了，收尾優先回扣同一句諺語。

## 2. 正文敘事節奏

循環單元：`NS 開場 → 一句畫面白描 → 資訊句 → SB → 承接句`。

**寫作程序（裁定①）**：口白一律**先成句後切行**——先寫帶標點的完整句草稿（節奏、鉤連、對仗在這一步定型），再於自然詞組邊界切成 ≤14 全形字的字幕行並去標點。禁止逐 14 字直接造句。**設問句保護（裁定⑥）**：設問句設計時就控制在 ≤14 字、整句一行，不可切開；保留標點的語體（稿頭、SOT 草稿）中「？」視為不可分離句尾。

1. OS 連續 ≤3 句就換氣（插 NS 或 SB）；密集動作段可連放 3–4 個 NS、每個只跟 1 句短描述；要放慢就在 NS 後接 2–3 句完整資訊句。
2. 只有照片素材時寫 `NS 快門聲` 再描述。
3. **SB 前後都要有橋**：SB 前一句丟立場或問題；SB 後第一句**必須回應剛才的引語**（同意／反駁／補充／翻面），不可跳到無關新資訊。
4. **設問引擎**（正文專用）：每篇 1–3 個自問自答句放在「換子題」接縫，問句後 2 個元素內（SB/CG/OS）必須給答案。句式：「到底…？」「那…又有何良策？」「真的嗎？」「…有可能嗎？事實上…」「難道…嗎。原來…」。稿頭與收尾禁用問號。
5. **賣關子**每篇 ≤1 次：半句懸念 → NS → 「沒錯，就是…／原來是…」立刻揭曉。

## 3. 對比與對仗

1. 「不過／卻／然而／只是」是**換視角訊號**：只在前後主詞或立場不同時用；同一主詞順向敘事禁用。全篇 ≤6 次；「甚至／更」遞進 ≤3 次。
2. 每篇 1–2 個「四字＋四字」對仗短語，放段落收尾（「成王敗寇，一夕翻轉」型）。
3. 衝突題材做一次空間對照：「一邊／另一邊」「距離只有 N 公尺」。
4. 「別人…他們…」對照句是穩定簽名句式（「別人賞煙火，他們躲砲火」「別人慶祝耶誕，他們跌入煉獄」），適用場景出現時優先使用。

## 4. 比喻開關（判準：有無死亡悲劇）

| 開關 | 條件 | 額度 |
|---|---|---|
| **關** | 稿內有死亡悲劇 | 比喻 ≤1 個定調詞（「人間煉獄」級），禁戲謔、禁雙關 |
| **半開** | 財經、無死亡的災害治安稿 | 具象化比喻翻譯抽象概念（「漲聲響起」「免死金牌」） |
| **全開** | 武器、體育、政治攻防、**輕民生/獵奇**（彩券、迎財神） | 每 300 字 1–2 個，可玩次文化梗 |

- 取材優先序：日常俗語 ＞ 流行/電玩梗 ＞ 文言成語；一秒看懂、不疊兩層。
- **嘲諷白名單**：只嘲諷掌權者、加害者、鬧劇主角；受害者、災民、平民一律不得戲謔。嘲諷用具象小動作（「氣噗噗」「敲鑼打鼓」），不用惡毒形容詞。
- 擬人動詞用在武器、機構、市場上（無人機像禿鷹、道瓊嚇崩、政府踢皮球）。

## 5. 情緒紀律（情緒外包）

**情緒讓 SB 講；OS 只做動作白描＋一句人性註腳。**

1. 公式：`具體動作白描（1–2 句）→ 當事人 SB → 人性註腳（15–25 字，帶普遍性人生觀察）`。
2. **禁令**：OS 不得出現「令人心碎、催淚、震撼人心、悲痛萬分」等替觀眾規定情緒的詞。可用中性強度詞：「令人頭皮發麻」「餘悸猶存」「看不下去」。
3. 荒謬題材配一個反諷收束（借現成典故：何不食肉糜），每篇一次。
4. **數字即情緒**：慘烈數字翻譯成生活尺度（美元→台幣）後直接放，不加形容詞。

## 6. 簽名層（高風險手法，嚴守額度）

| 手法 | 額度 | 條件 |
|---|---|---|
| 諧音改字（升升不息、取財有到） | 每篇 ≤1 | 限標題與輕鬆稿 OS；改字須一秒還原原詞 |
| 物件雙關回扣收尾（搖頭公仔→消費者搖頭嘆氣） | — | 收尾前先掃描稿內可雙關物件，有就優先於一般俗語收尾 |
| 吐槽式 OS（「所以我說那個備忘錄呢？」） | 每篇 ≤1 | 只在官方說法明顯敷衍或反差揭曉時；對象限機構/掌權者。過量即「網紅腔」 |
| 台語/網路語（剉咧等、氣噗噗） | 每篇 ≤2 | 限體育、政治嘲諷、消費民生；死傷人道稿禁用 |

死傷稿全面禁用雙關與以上全部戲謔手法。

## 7. 標題（網路標）

1. 兩段式：`前半 8–11 字 ＋ 半形空格 ＋ 後半 8–11 字`，前半管情緒/懸念、後半管事實/引語，各自能獨立成句。四型：驚嘆前置／設問／冒號引語／數字反差。
2. 驚嘆號只放前半句尾；帶驚嘆號的標題 ≤ 總數 1/3（人稿實測僅 ~5%，寧缺勿濫）。
3. 冒號句型 `人名:引語`——引語壓縮到 4–8 字，保留原話最尖的詞。
4. 新奇詞/爭議詞加引號；國名用慣用縮寫（陸、美、日、韓、烏、以）。
5. **雙軌產出（裁定②）**：每張 BAR／每個標題切角同時給「長版（18–22 字，保留完整三段結構，含全形空格，可用頓號引號）＋壓縮版（符合現行字數規則，上鏡用）」。長版**不寫進完成文稿本體**（隨交付訊息附上，或另存 `<ID> 網路標.txt`），驗證器只驗檔內壓縮版。
6. 字數/標點以現行格式規則為準（BAR 16.5–17.5、SOT 標題 17.5–18.5、白名單 `! " + : . %`）。

## 8. 收尾（簽名句）

最後一句＝**不含新事實的判斷/展望句，12–30 字**（長專題放寬到 40）。選型：

| 型 | 條件 | 句尾詞庫/模板 |
|---|---|---|
| 懸置展望 | 事件未完 | 「恐怕…」「就看…」「能否…備受關注」「才要開始」 |
| 俗語判斷 | 有明確荒謬點或贏家輸家 | 每篇 ≤1 句，須與主題雙關連結（球賽→輸贏靠自己） |
| 回扣 | 開頭有強意象 | 回到開場意象/人物；有可雙關物件優先（第 6 節） |
| 格言 | 專題/週年/大歷史題 | 極低頻，勿常用 |
| 條件句裁決（長專題） | 見第 9 節 | `若/一旦/只要 ＋ 等於/恐怕/就是`；「縮影/啟示錄/陷阱」收束詞 |

## 9. 長篇專題（另一套結構，勿與日常稿共用模板）

**適用條件（裁定⑤）**：使用者明確下令「長篇專題」才套用本節；結構豁免（SB 連發合法、總長不受 120 秒預設限制）見 [`06-auto-script-sot.md`](06-auto-script-sot.md) 長專題專節。日常 SOT/CTV 維持各自現行結構。

1. **問題清單骨架**：先列 2–4 條大哉問當區塊大綱，每塊 400–700 字，塊間用設問句轉場；每塊自帶「小開場（NS/現場）→ 論證（SB 接力）→ 小結一句」。
2. **四層推軌**：開場永遠是單一具體現場（禁「綜觀全局」式開場）→ 區域掃描 → 戰略分析 → 最後一層才出現「對台灣/全球來說」。
3. **專家 SB 接力**：同一論點 2–3 個專家 SB 連發，OS 退居 8–20 字的橋；每組接力後 OS 用「換而言之/換句話說＋條件句」裁出本段結論。
4. **規格書段落**（軍武/機制）：`NS 畫面 → 一句身世 → 最多 3 個規格數字（超過進 CG）→ 一句戰術意義收尾`。
5. **時間戳圖卡**：進行中事件（颱風、選舉夜、戰事）用時間戳序列當骨架，OS 每格一句導讀。
6. **台灣錨點**：交稿前自查中後段有無台灣連結；沒有自然連結就用台幣換算/台灣參照物補位，不硬掰政治連結。

## 10. 內幕改寫模板（外媒獨家）

`外媒名＋「披露內幕」→ 時間戳分格（3–5 格，每格一個主詞一個動作）→ 最小生活化細節收束（「今晚不必加班」級）→ 一句懸念`。全程標註消息來源；推測語用「恐怕/可能/據傳」。

## 11. 用字習慣

1. **動詞升級表**（寫完自查替換）：下跌→重挫/嚇崩、聚集→擠爆/塞爆、批評→痛批/開嗆、否認→矢口否認、拆除→連根拔起、上漲→狂飆。
2. 口語詞（拜碼頭、踢皮球、燙手山芋、找台階下）與國中程度成語（木已成舟、擦槍走火、雪上加霜）交替當節奏件，不炫技。
3. 首次出現的外國人名：`身分＋中文譯名`；罕見譯名可用【】強調（格式細節仍以各流程文件為準）。
4. 新概念緊跟白話解釋：「也就是…／指的是…／俗稱…」。
5. 單位在地化：外幣 ≥ 百萬美元附台幣（換算規則見 [`00-寫稿通則.md`](00-寫稿通則.md)，含連續金額只換 TOTAL 的 `P-016`）；面積用有感參照物（「超過舊金山市區」）。
6. **避免**：歐化長定語、書面文言虛詞（之、乃、遂）、「進行了…」贅語、替觀眾規定情緒的形容詞。

## 12. 生成檢核表（交付前逐項自查）

- [ ] 語體三選一（SOT/快訊 BS/連線；長專題另套），未混排
- [ ] 稿頭末句是鉤子；判斷語 ≤1；稿頭無問號、無素材編號；句讀正常
- [ ] 正文設問 1–3 次且 2 個元素內解答；賣關子 ≤1；收尾無問號
- [ ] 每則 SB 後第一句回應引語；OS 連續 ≤3 句換氣；照片用快門聲
- [ ] 轉折詞 ≤6 且前後立場確實不同；對仗短語 1–2 處在段落收尾
- [ ] 比喻依「死亡開關」控制；死傷稿禁戲謔禁雙關；嘲諷只對掌權者/加害者
- [ ] 情緒段＝白描→SB→15–25 字註腳；無「令人心碎」類指令詞
- [ ] 諧音雙關 ≤1、吐槽 OS ≤1、台語網路語 ≤2，題材皆合宜
- [ ] 標題兩段式、驚嘆號僅前半尾且 ≤1/3、冒號引語 4–8 字；長短版雙軌
- [ ] 收尾 12–30 字判斷/展望句、不含新事實；有可雙關物件優先回扣
- [ ] 動詞已升級；外幣已換台幣；新名詞已白話解釋
- [ ] 無佔位符、無內部指令、無素材編號、無錯字、無個資/帳密（詳見 B1/B2「不要學」清單）
- [ ] 格式規則全過（`validate_sot.py` 對應 mode，exit 0）
