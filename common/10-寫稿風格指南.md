# 寫稿風格指南（人味層）

**定位**：本文件是「風格參照層」，合成自 [`../style-corpus/`](../style-corpus/README.md) 的九份分析（[A 統計](../style-corpus/analysis_A_report.md)／[B1](../style-corpus/analysis_B_fable.md)／[B2](../style-corpus/analysis_B2_fable.md)／[B3](../style-corpus/analysis_B3_fable.md)／[B4](../style-corpus/analysis_B4_fable.md)／[B5](../style-corpus/analysis_B5.md)／[B6](../style-corpus/analysis_B6.md)／[B7](../style-corpus/analysis_B7.md)／[B8](../style-corpus/analysis_B8.md)，**共精讀 308 篇**許岱軒親筆完成稿）。目標：讓自動寫稿（CTV／SOT）的產出更接近使用者本人的聲音。

**優先序**：本指南**不覆蓋**既有格式規則（`P-001`~`P-021`、字數上限、五行 SB、驗證器檢查）。兩者衝突時以格式規則為準，衝突點集中列在文末「待裁定張力」，由使用者裁決後才調整。

**使用方式**：寫稿代理起稿前讀本指南；交付前跑文末「生成檢核表」自查。原句證據都在 B1/B2 報告裡，本文只留規則與模板，不重複引文。

## 0. 語體判定（動筆前先選一種，禁止混排）

| 語體 | 特徵 | 適用 |
|---|---|---|
| **SOT／CTV 完成稿** | 稿頭帶標點＋正文斷行＋SB/NS 標記 | 預設 |
| **快訊 BS** | 「國際最新消息，…」開場，150–250 字一段式，無 SB | 突發快訊 |
| **連線口播** | 無標點短行，「好的主播」開場，「以上是為您掌握的最新情形」收尾，允許重複關鍵資訊 | 連線 |
| **長篇專題** | 見第 9 節，另一套結構 | 9000 字級專題 |

> ⚠️ **語體維持四分法（B6 修正）。** B4 曾把「影音變色強調體」立為第五語體，B5／B6 用精準判準掃過全語料確認**只有 2 個標本**（0508-2 炸橋、0531-3 執法記錄器，題材毫無交集）。2 個標本無法歸納觸發條件與密度上限，且維持「五種語體」會讓分類時把它當雜訊類別——**要嘛永遠不選、要嘛亂選**。故**撤銷語體地位**，其標記語法保留為附加交付件，見第 16 節「短影音強調標記」。

## 1. 稿頭（開場）

句序固定：`規模事實（含 1–2 個數字）→ 轉折詞 → 鉤子（放最後一句）`。四型擇一：

- **A 數字衝擊＋反常個案**（災難稿主力）：數字先砸，再接一個「唯獨／竟然」的個案。
- **B 雙場景對照**：兩個畫面並置，靠「同一時間／而／不過」硬接。
- **C 事件＋判斷語收尾**（政治外交主力）：末句用判斷語庫「似乎是…／顯見…／恐怕…／等於是…／意味著…」，**每篇最多一句**，不疊加。
- **D 觀眾利益切入**（民生／旅遊／消費）：第一句直接向觀眾示警或報好康，允許驚嘆號。
- **E 觀感驚嘆前置型**（B6 新增第五型，5 篇標本）：第一句先給**觀感式驚嘆**（不是價值判斷、不是事實），再接事實。與 B3 的「判斷前置型」不同——那是下價值判斷（「真的是台灣之恥」，需三條件齊備），這是描述觀感（規模、奇觀、反常），門檻低得多。

規則：稿頭不用問句（設問留給正文）；不出現素材編號、引語全文；保留正常中文句讀（`P-014`）。**鉤子優先於字數（裁定③）**：A 型稿頭為保末句鉤子可寫到 180 字、接受 WARN；確實過長時優先精簡中段事實，絕不砍鉤子。

> ⚠️ **「稿頭不用問句」的唯一例外：舊聞回鍋（B7-M3 修正）。** 主角是觀眾**曾經熟悉、但已久未出現**的人物或事件時，可用「還記得他嗎？」型疑問句喚回記憶——比重述背景省字，且問句本身就是鉤子。條件嚴格：①主角確實曾是全國級新聞 ②距上次上新聞已有相當時間 ③問句後**立刻**用一句話補完身分與當年事由。不符合就回到不用問句的通則。

**變體（每篇 ≤1 次，限反差/趣聞/體育）**：諺語翻轉開場——`國民級慣用語 →「這句話不適用／都不如／還真不是」→ 主角`；若用了，收尾優先回扣同一句諺語。

> **諺語翻轉也可以只出現在標題（B8-U40 新增）。** 不一定要鋪成整段開場，把諺語壓縮進標題前半句同樣成立，而且更省字：
> > **紅潮退找褲穿?** 民主黨奪關鍵州可望保住參院
>
> 化用巴菲特「退潮才知道誰沒穿褲子」，且「紅潮」本來就是這則新聞的關鍵詞——**諺語裡的詞要跟新聞主詞天然咬合，硬套就會尬**。標題版與開場版擇一，不要同一篇兩處都用。

**變體：題材語彙開場（B7 升格為通用招，來源 U1＋U20）**——開場的語彙直接取自該題材自身，讓觀眾第一秒就認出稿件屬性：

| 題材 | 取材 | 實例 |
|---|---|---|
| 教育校園 | 上課口令、校園歌謠 | 「起立立正，今天上課教室是白宮，今天代課老師，美國總統川普。」／「背著書包上學去／烏克蘭小學生回到校園／響起的不是上課鐘聲／而是警報鈴聲」 |
| 訃聞追悼 | 逝者的招牌作品語彙 | 「龜派氣功絕響」「鳥山明修煉去」（見 14g「作品語彙轉喻死亡」） |
| 法庭審判 | 庭訊程序語言 | 見 14g「外觀＋沉默開場」「程序性對話當 SB」 |

與「否證反轉」（14g U17）併用效果最強：先用題材語彙鋪出預期，再一句「響起的不是…而是…」翻面。**每篇 ≤1 次**；語彙必須是台灣觀眾的共同記憶，冷僻典故不算。

## 2. 正文敘事節奏

循環單元：`NS 開場 → 一句畫面白描 → 資訊句 → SB → 承接句`。

**寫作程序（裁定①）**：口白一律**先成句後切行**——先寫帶標點的完整句草稿（節奏、鉤連、對仗在這一步定型），再於自然詞組邊界切成 ≤14 全形字的字幕行並去標點。禁止逐 14 字直接造句。**設問句保護（裁定⑥）**：設問句設計時就控制在 ≤14 字、整句一行，不可切開；保留標點的語體（稿頭、SOT 草稿）中「？」視為不可分離句尾。

1. OS 連續 ≤3 句就換氣（插 NS 或 SB）；密集動作段可連放 3–4 個 NS、每個只跟 1 句短描述；要放慢就在 NS 後接 2–3 句完整資訊句。
2. 只有照片素材時寫 `NS 快門聲` 再描述。
3. **SB 前後都要有橋**：SB 前一句丟立場或問題；SB 後第一句**必須回應剛才的引語**（同意／反駁／補充／翻面），不可跳到無關新資訊。
4. **設問引擎**（正文專用）：每篇 1–3 個自問自答句放在「換子題」接縫，問句後 2 個元素內（SB/CG/OS）必須給答案。句式：「到底…？」「那…又有何良策？」「真的嗎？」「…有可能嗎？事實上…」「難道…嗎。原來…」。稿頭與收尾禁用問號。
5. **賣關子**每篇 ≤1 次：半句懸念 → NS → 「沒錯，就是…／原來是…」立刻揭曉。

## 3. 對比與對仗

1. 「不過／卻／然而／只是」是**換視角訊號**：只在前後主詞或立場不同時用；同一主詞順向敘事禁用。全篇 ≤6 次；「甚至／更」遞進 ≤3 次。
2. 每篇 1–2 個「四字＋四字」對仗短語，放段落收尾（「成王敗寇，一夕翻轉」型）。
3. 衝突題材做一次空間對照：「一邊／另一邊」「距離只有 N 公尺」。
4. 「別人…他們…」對照句是穩定簽名句式（「別人賞煙火，他們躲砲火」「別人慶祝耶誕，他們跌入煉獄」），適用場景出現時優先使用。

## 4. 比喻開關（**段落級**判準，B6 修正；B7 補死亡類型判準）

判準有三層，依序套用：

**第一層——作用範圍是段落，不是整篇（B6 硬修正）。** 舊版「全篇有死亡就整篇關閉」過嚴且不符實際。

**第二層——隱喻箭頭指向誰（B6）：**

> **指向加害者的隱喻可以存活；指向受害者的一律禁止。** 即使全篇有隱喻框架，**死者段落內一律關閉**。

**第三層——死亡是「意外奪走」還是「壽終儀典」（B7-M1 硬修正）：**

> 舊版把「有死亡」一律當關閉訊號，但訃聞與國葬稿的比喻其實是**開**的。真正的分界是死亡怎麼來的。

| 死亡類型 | 開關 | 實測 |
|---|---|---|
| **意外／暴力奪走**（災難、事故、命案、戰爭） | **關**，要比喻就外包給 SB | 印度火車 275 死、小林製藥 4 死：OS 全篇零比喻。柯克命案：比喻全部由 CNN 主播講（「就像洋娃娃或雕像」） |
| **壽終／國葬／儀典** | **開**，但**只准用在「生平成就」與「儀典場景」段** | 鳥山明：「生涯就像他筆下的悟空一樣，打通天下一武道大會」。女王靈車：「靈柩依然如皇冠鑽石般耀眼奪目」 |

壽終稿開比喻時的紅線：**死亡瞬間本身仍然不能比喻**，比喻只服務於「他這一生做過什麼」與「現場看起來怎樣」。

| 開關 | 條件 | 額度 |
|---|---|---|
| **關** | 意外／暴力死亡已確認的段落；**動物大量死亡**亦適用（受害者包含動物與生態——牠們不能自辯） | 比喻 ≤1 個定調詞（「人間煉獄」級），禁戲謔、禁雙關、禁換算比喻 |
| **半開** | 財經、無死亡的災害治安稿；**搜救中（生還仍有可能）**；**訃聞／國葬的生平成就段與儀典場景段** | 具象化比喻翻譯抽象概念（「漲聲響起」「深海棺材」「大海撈針」） |
| **全開** | 武器、體育、政治攻防、**輕民生/獵奇**（彩券、迎財神）、**太空科研**（無死者無受害者） | 每 300 字 1–2 個，可玩次文化梗 |

- 死亡確認稿**唯一可用的加冕手法是「反事實英雄化」**（若不是他……就會……）——因為那是事實推論，不是修辭。
- 取材優先序：日常俗語 ＞ 流行/電玩梗 ＞ 文言成語；一秒看懂、不疊兩層。
- **嘲諷白名單**：只嘲諷掌權者、加害者、鬧劇主角；受害者、災民、平民一律不得戲謔。嘲諷用具象小動作（「氣噗噗」「敲鑼打鼓」），不用惡毒形容詞。
- 擬人動詞用在武器、機構、市場上（無人機像禿鷹、道瓊嚇崩、政府踢皮球）；**新增第四類：AI／自動化系統**（演算法、自駕系統），但**造成傷亡時禁用擬人**。

## 5. 情緒紀律（情緒外包）

**情緒讓 SB 講；OS 只做動作白描＋一句人性註腳。**

**外包給誰隨題材改變（B6 新增對照表）**——紀律不變，載體不同：

| 題材 | 情緒外包對象 |
|---|---|
| 戰爭／人道 | 當事人 SB |
| 娛樂名人 | **網友**（「網友笑稱…」）——**不可外包給粉絲 SB**，那等於替粉絲加碼 |
| 環境生態 | **動物的動作**（白描，零形容詞） |
| 醫療公衛 | **數據**（藥價本來/現在對照） |
| 經濟財經 | **業者行為**（漲價、關店、排隊） |
| **移民難民**（B7 新增） | 當事人 SB；**OS 改用「同詞反轉」代替比喻**——「紐約這座『庇護城市』，對滯留的偷渡客來說已經成為『恐懼之城』」。移民稿有明確受害者，OS 不比喻，但可以把同一個詞翻面 |
| **勞資爭議**（B7 新增） | 當事人 SB ＋ **數字堆疊**（時薪 16.5 美元 vs 從前 100 美元、1000 封履歷回覆率 4%），全部換算台幣，不加形容詞 |

1. 公式：`具體動作白描（1–2 句）→ 當事人 SB → 人性註腳（15–25 字，帶普遍性人生觀察）`。
2. **禁令**：OS 不得出現「令人心碎、催淚、震撼人心、悲痛萬分」等替觀眾規定情緒的詞。可用中性強度詞：「令人頭皮發麻」「餘悸猶存」「看不下去」。
3. 荒謬題材配一個反諷收束（借現成典故：何不食肉糜），每篇一次。
4. **數字即情緒**：慘烈數字翻譯成生活尺度（美元→台幣）後直接放，不加形容詞。

## 6. 簽名層（高風險手法，嚴守額度）

| 手法 | 額度 | 條件 |
|---|---|---|
| 諧音改字（升升不息、取財有到） | 每篇 ≤1 | 限標題與輕鬆稿 OS；改字須一秒還原原詞 |
| 物件雙關回扣收尾（搖頭公仔→消費者搖頭嘆氣） | — | 收尾前先掃描稿內可雙關物件，有就優先於一般俗語收尾 |
| 吐槽式 OS（「所以我說那個備忘錄呢？」） | **分級（B5 修正）**：主題本身就是出糗／失言 → ≤3 處；其餘一律 ≤1 | 只在官方說法明顯敷衍或反差揭曉時；對象限機構/掌權者。過量即「網紅腔」 |

> **法庭稿的吐槽開關：看案件有沒有死者（B7-M2 硬修正）。** 過去只問「當事人是不是公眾人物」，但實測顯示那不是分界——川普性侵民事案與柯克命案的被告都是知名人物，前者吐槽全開（「如今判決下來**臉很腫**」「委任律師連也變**過街老鼠**」），後者 OS 零吐槽、比喻全外包給 CNN 主播。
> - **案件有死者** → OS 不吐槽、不比喻，情緒與評價一律外包
> - **純民事／名譽／貪瀆** → 可吐槽，且箭頭須指向**敗訴方或被告方**（與第 4 節的加害者箭頭規則一致）
| 台語/網路語（剉咧等、氣噗噗） | **改用「觸發＋用途」模型（B6 硬修正，取代 B5 的配額分級）**：不預設篇數配額，改看**有沒有觸發用途**——①**爽快語氣**（限 SB 譯文，當事人講得痛快時）②**體恤弱勢**（不限題材）③嘲諷掌權者④輕鬆題材的節奏點 | **取消戰爭稿絕對禁令**——體恤弱勢的用法在戰爭稿同樣成立；仍不可用於嘲笑受害者。實測 43 篇僅出現 2 次，本來就是稀用手法，不必設上限 |

死傷稿全面禁用雙關與以上全部戲謔手法。

## 7. 標題（網路標）

1. 兩段式：`前半 8–11 字 ＋ 半形空格 ＋ 後半 8–11 字`，前半管情緒/懸念、後半管事實/引語，各自能獨立成句。四型：驚嘆前置／設問／冒號引語／數字反差。
2. 驚嘆號只放前半句尾；帶驚嘆號的標題 ≤ 總數 1/3（人稿實測僅 ~5%，寧缺勿濫）。
3. 冒號句型 `人名:引語`——引語壓縮到 4–8 字，保留原話最尖的詞。
4. 新奇詞/爭議詞加引號；國名用慣用縮寫（陸、美、日、韓、烏、以）。
5. **雙軌產出（裁定②）**：每張 BAR／每個標題切角同時給「長版（18–22 字，保留完整三段結構，含全形空格，可用頓號引號）＋壓縮版（符合現行字數規則，上鏡用）」。長版**不寫進完成文稿本體**（隨交付訊息附上，或另存 `<ID> 網路標.txt`），驗證器只驗檔內壓縮版。
6. 字數/標點以現行格式規則為準（BAR 16.5–17.5、SOT 標題 17.5–18.5、白名單 `! " + : . %`）。

## 8. 收尾（簽名句）

最後一句＝**不含新事實的判斷/展望句，12–30 字**（長專題放寬到 40）。選型：

| 型 | 條件 | 句尾詞庫/模板 |
|---|---|---|
| 懸置展望 | 事件未完 | 「恐怕…」「就看…」「能否…備受關注」「才要開始」 |
| 俗語判斷 | 有明確荒謬點或贏家輸家 | 每篇 ≤1 句，須與主題雙關連結（球賽→輸贏靠自己） |
| 回扣 | 開頭有強意象 | 回到開場意象/人物；有可雙關物件優先（第 6 節） |
| 格言 | 專題/週年/大歷史題 | 極低頻，勿常用 |
| 條件句裁決（長專題） | 見第 9 節 | `若/一旦/只要 ＋ 等於/恐怕/就是`；「縮影/啟示錄/陷阱」收束詞 |

## 9. 長篇專題（另一套結構，勿與日常稿共用模板）

**適用條件（裁定⑤）**：使用者明確下令「長篇專題」才套用本節；結構豁免（SB 連發合法、總長不受 120 秒預設限制）見 [`06-auto-script-sot.md`](06-auto-script-sot.md) 長專題專節。日常 SOT/CTV 維持各自現行結構。

1. **問題清單骨架**：先列 2–4 條大哉問當區塊大綱，每塊 400–700 字，塊間用設問句轉場；每塊自帶「小開場（NS/現場）→ 論證（SB 接力）→ 小結一句」。
2. **四層推軌**：開場永遠是單一具體現場（禁「綜觀全局」式開場）→ 區域掃描 → 戰略分析 → 最後一層才出現「對台灣/全球來說」。
3. **專家 SB 接力**：同一論點 2–3 個專家 SB 連發，OS 退居 8–20 字的橋；每組接力後 OS 用「換而言之/換句話說＋條件句」裁出本段結論。
4. **規格書段落**（軍武/機制）：`NS 畫面 → 一句身世 → 最多 3 個規格數字（超過進 CG）→ 一句戰術意義收尾`。
5. **時間戳圖卡**：進行中事件（颱風、選舉夜、戰事）用時間戳序列當骨架，OS 每格一句導讀。
6. **台灣錨點**：交稿前自查中後段有無台灣連結；沒有自然連結就用台幣換算/台灣參照物補位，不硬掰政治連結。

> ⚠️ **外國選舉稿：台灣錨點升級為位置硬規則（B7-M4）。** 不是「中後段有提到就好」，而是**當選人／主要候選人的對台立場，必須寫進第一次提到他的那一句裡**：
> - 「宏都拉斯選委會宣布，**支持和台灣復交的**、67歲的保守派候選人【阿斯拉夫】，以40.26%得票率…」
> - 「她對中強硬出名，**是對台灣最友善的候選人**，曾說不要讓台灣變成第二個香港，3年前還跟時任總統蔡英文通過視訊電話。」
>
> 理由：台灣觀眾對外國政治人物唯一的判斷座標就是對台立場，晚一段給等於前面那段白聽。適用於所有外國大選、黨魁改選、內閣改組稿，**不限長專題**。

## 10. 內幕改寫模板（外媒獨家）

`外媒名＋「披露內幕」→ 時間戳分格（3–5 格，每格一個主詞一個動作）→ 最小生活化細節收束（「今晚不必加班」級）→ 一句懸念`。全程標註消息來源；推測語用「恐怕/可能/據傳」。

## 11. 用字習慣

1. **動詞升級表**（寫完自查替換）：下跌→重挫/嚇崩、聚集→擠爆/塞爆、批評→痛批/開嗆、否認→矢口否認、拆除→連根拔起、上漲→狂飆。
2. 口語詞（拜碼頭、踢皮球、燙手山芋、找台階下）與國中程度成語（木已成舟、擦槍走火、雪上加霜）交替當節奏件，不炫技。
3. 首次出現的外國人名：`身分＋中文譯名`；罕見譯名可用【】強調（格式細節仍以各流程文件為準）。
4. 新概念緊跟白話解釋：「也就是…／指的是…／俗稱…」。**判準是「台灣觀眾熟不熟」，不是「這個詞專不專業」（B5 修正）**——專業詞若台灣觀眾天天聽（如颱風強度分級）不必解釋；反之外國的日常詞若台灣沒有對應經驗（如某國選制、當地連鎖品牌），再普通也要解釋。這條影響每一篇稿。
5. 單位在地化：外幣 ≥ 百萬美元附台幣（換算規則見 [`00-寫稿通則.md`](00-寫稿通則.md)，含連續金額只換 TOTAL 的 `P-016`）；面積用有感參照物（「超過舊金山市區」）。
6. **避免**：歐化長定語、書面文言虛詞（之、乃、遂）、「進行了…」贅語、替觀眾規定情緒的形容詞。
7. **三個轉折標記（B7-M6，跨題材通用簽名）**——各有專屬功能，不可互換：

| 標記 | 功能 | 實例 |
|---|---|---|
| **抱歉** | 拆掉自己上一句剛設定的期待（搭配 14g「期待—拆台二拍」） | 「川普喊出美國製造業復興，應該是利多吧？…**抱歉**業者挺的還是賀錦麗。」 |
| **這回** | 把單一個案接回趨勢，或標示輪到誰了 | 「**這回**裁員轉盤轉到的，竟然是科技業龍頭的微軟。」 |
| **不演了** | 把「官方說法→遭質疑→官方承認」三步壓成一句 | 「一開始對外說是為了統計與分配資源…後來總監乾脆**不演了**，沒錯就是幫川普。」 |

每篇各 ≤1 次；「不演了」限官方確實改口的情況，不可用於記者自行推論。

## 14. 稀有招式庫（B3 獵寶輪，2026-07-25 增補；低頻高辨識度，依時機取用）

來源：[B3 報告](../style-corpus/analysis_B3_fable.md)（60 篇未讀池，含超長稿與短稿語域）。原句證據與完整解構都在報告裡，這裡只留模板與額度。**這些是「時機到才出手」的招，不是每篇必備**——強求則尬。

### 14a. 敘事類

| 招式 | 模板 | 時機／上限 |
|---|---|---|
| **全篇延伸隱喻** | 選定與日期/性質強相關的生活腳本（節日、球賽、牌局）→ 標題「別人A，他們B」定調 → 正文 ≥3 處把衝突動作翻譯成腳本詞彙（砲擊=煙火）→ 收尾回到腳本（許願/終局） | 節日撞衝突、體育式攻防專用；月 ≤1 次；死傷細節段內禁用腳本詞彙 |
| **場景接力雙關** | 前畫面是生活動作（吃、睡）、後畫面是衝突動作 → 用前者動詞雙關後者（「飯還沒吃完…先請敵軍飽餐一頓」）；成語優先挑含主題意象的（武器稿→箭在弦上） | 前線直擊、監視器素材；每篇 ≤1 |
| **入戲—拆台二段式** | 宣傳片/AI 假影片 → 前 2–3 句劇情片語氣照演（保留最荒謬細節）→ 一句拆台（「魔幻情節」「真實性有待商榷」）→ 一句動機裁決（大內宣） | 官方宣傳片、擺拍素材專用；拆台句須有消息源或明顯造假特徵背書 |
| **倒帶敘事** | 結果畫面先行（爆炸/淹沒）→「時間倒回X分鐘前」→ 因果畫面 → 一句歸因；縮時素材每格一句、現在進行式 | 有「結果+過程」雙素材才用；每篇 ≤1 |
| **迷因指標入稿**（使用者常用） | 重大倒數題材＋可查證的非正式指標（披薩指數、搜尋量暴增）→「連『XX指數』也…」當氣氛旁證，主證據（官員/媒體）在前 | 只能當第二證據；須可查證；不點名特定指數為必用 |
| **反向成全反諷**（存檔提醒） | 加害行為意外達成受害方既有目標 →「誤幫…完成了…」收束 | 極稀有；需查證受害方確有此目標；**遇到請不要錯過，但不可強求** |

### 14b. 語言類

| 招式 | 模板 | 時機／上限 |
|---|---|---|
| **台灣文化嫁接** | **取材優先序（B5 升級）：身體記憶 ＞ 童年遊戲 ＞ 廚房家電 ＞ 運動器材 ＞ 單位換算 ＞ 語錄**。抽象機制→廚房家電（電鍋）；外國面積→台北市/大安區倍數（可帶小數），**大範圍改用「N 個台灣」**；戲劇化人情事件→國民級影視梗 | 文化梗每篇 ≤1；影視梗限輕鬆題材；單位換算無限制、**應成標配** |

> **單位換算不限面積（B8-M11 修正）。** 舊版只寫「面積換算」，實測顯示這一招可套到**任何可比單位**，而且是勞資／民生／經濟稿的主力：
>
> | 單位 | 實例 |
> |---|---|
> | 速度 | 鐵路工會降速抗議，「時速只有30公里，**比台北市公車速限40公里還慢**」 |
> | 佔比 | 「電費佔一般家庭收入比4-6成，**相對台灣家庭只佔不到1%**」 |
> | 單價 | 「巴基斯坦人均GDP是台灣的21分之一，每公升柴油要32台幣，**竟然還比台灣貴3元**」 |
> | 面積 | 台北市／大安區倍數；大範圍用「N 個台灣」（原規則不變） |
>
> 最強形態是**兩段式落差**：先給一個「他們比我們窮很多」的錨，再翻出「可是這樣東西他們還比我們貴」。模板與更多原句見 14h。
| **諧音替字＋姓名雙關**（使用者常用） | 諧音限標題、一字之替（惡棍→俄棍），正文須出現原詞解碼；人名先掃描是否嵌在現成成語（威→下馬威） | 輕鬆稿與體育稿限定；每篇 ≤1；死傷稿禁用 |
| **迷因稱號借用**（使用者常用） | 傳奇人物戲劇性回歸/發威 →「難道是，『辣個男人』回來了？」／「不愧是…的『辣個男人』」，配問號或「不愧是」緩衝 | 限狠角色、非悲劇語境；一稿 ≤1、少用；留意梗的時效性 |
| **髒話合規轉寫** | SB 髒話以「X你X／他X的」轉寫 → OS 用「一連串國罵，消音都來不及」承接 | 衝突現場、名人失控名場面 |
| **拆字頓挫排版**（使用者常用） | 受訪者逐字咬字強調時，譯文用全形空格拆字（「就是 遊 民」）重現語氣 | 每篇 ≤1；上機前人工確認字幕系統相容 |
| **文學典故盲盒**（使用者常用） | 「本以為又是『西線無戰事』的一天…」句式埋反轉；典故須標題級知名且與畫面反差成立 | 每篇 ≤1；冷門典故禁用 |
| **民間語錄加冕** | 挑當事人 SB 最短最鈍的一句 → OS 以「短短幾個字，就是…的最佳寫照」或對仗擴寫加冕 → 作段落/全篇收尾 | 韌性/災後/抗爭題材；每篇 ≤1；不得替原話加碼 |
| **判斷前置稿頭**（使用者常用） | 僅當（本國人＋重大負面＋社會共識明確）三條件齊備 → 稿頭可用「真的是…」判斷開場，後續立即接事實 | 極端例外；政治爭議題材禁用（判斷無共識） |

### 14c. 結構類（篇幅模板補充）

- **全照片稿**：純照片素材 → 快門聲當節拍器（3–5 組），每組「快門聲→照片動作白描一句→意義句一句」；OS 動詞凝格化（跪在地上、指著天空）。體育頒獎、歷史瞬間專用。
- **短稿壓縮公式**（700–1200 字）：`單線敘事＋一組對照＋一個修辭點＋SB 金句＋判斷收尾`；NS/SB 元素 ≤6；禁第二條支線。**金句優先從素材逐字稿直取，不自行創作**（「我配不上他，我們都配不上他啦」式轉播原話＋OS 一句加冕）。
- **超長稿模板**（>20000 字，與第 9 節長專題是兩種結構）：`定義卡（新流行語/規格對比 CG）→ 個案小傳 ×3–4（一句身分卡→場景→SB→一個數字）→ 學者一段裁決 → 回扣定義卡收尾`；個案間對比排序。論證重心在庶民個案不在專家；工作本質是「策展」逐字稿，不是寫更多字。

## 15. 題材禁忌檢核（B6 新增，交付前逐題材對照）

前五輪的禁令幾乎全來自戰爭人道稿。B6 確認**其他題材有不同紅線，有些在戰爭稿裡根本不存在**：

| 題材 | 紅線 |
|---|---|
| **醫療／公衛** | 病患一律**不具名、不給可辨識病情**（專家則具名＋標機構，分界是「有無專業責任」）；**嘲諷限藥商／官方數據／謠言，病患與醫護不可作為修辭對象**；藥價醫材價換台幣並用「本來…現在…」對照 |
| **環境生態** | **動物大量死亡＝比喻開關關閉**（受害者包含動物，牠們不能自辯）；**不用寵物化形容詞**（可愛／療癒／萌）；**保育爭議必給兩面 SB**（單面呈現＝公關稿）；**可收在未解的兩難，不必給勵志結論**（與戰爭稿要求判斷句不同） |
| **娛樂名人** | **可以放大狂熱，不可以嘲笑狂熱**（粉絲不在嘲諷白名單——非掌權者非加害者）；玩笑話交給受訪者 SB 講、**OS 自己不玩**；尊重匿名要求但**可說明匿名原因**（原因本身就是新聞點） |
| **體育** | 收尾不下判斷（預測賽果是外行）；**對手不貶低**，敗方檢討讓敗方球迷 SB 自己講 |
| **災難／事故** | 死亡確認後比喻／雙關／換算比喻**全面關閉**；死者段落內一律關閉；**搜救中（生還仍可能）維持半開**；**死亡人數大的稿要一併寫畫面指令**（避開屍體與過清楚的照片，見 14g） |
| **禮儀／王室／峰會** | 站位座次的解讀**一律留白**（「仍留給外界解讀空間」）——慣例不是聲明，記者不能替當事機構宣布動機；**必須有對照組**才能解讀 |
| **奇聞／幽浮／超自然**（B7 新增 G1） | **必須用科學解釋收掉，不能停在神秘。** 固定結構：鋪神秘 → 查無實證 → 科學打臉 → 官方數據收尾。吐槽可以全開（連員警的失態反應都能當笑點），但**結論必須落地** |
| **宗教／信仰**（B7 新增 G2） | **嘲諷箭頭只能指向政治人物，不能指向信仰、信徒或儀典本身。** 教宗稿對川普大量吐槽（瞎指、嘴硬、頭號黑粉），對教宗、教會、信徒零嘲弄；百萬信徒的集會稿零吐槽，連「披薩要厚片還是薄片」都是選來當可愛、不是當荒謬 |
| **宗教場所受襲**（B7 新增 G3） | **價值序是「古蹟 ＞ 人命」，與一般災難稿相反，寫這類稿要刻意切換。** 耶路撒冷稿零傷亡描述、全篇重點是「距圓頂清真寺 500 公尺、古蹟未受損」；奧德薩稿 2 死 22 傷一句帶過，主軸是 200 年大教堂被毀 →「摧毀的都是烏克蘭的文化記憶」。理由是文化遺產的不可回復性才是新聞點 |
| **勞資爭議**（B7 新增 G4） | **受害者不能吐槽。** 被裁員者、罷工者、丟包裹的司機一律中性敘述（「理由是壓力太大了」），吐槽全打在企業、資方與 AI（貝佐斯 196 億婚禮、80 歲創辦人的「爺孫戀」） |
| **法庭：家屬說情**（B8 新增 G5） | **說情的 SB 要放，但 OS 不評論說情內容本身**——不說「說詞牽強」也不說「令人同情」，只接客觀後果：〔胞妹 SB：他出生就有身心疾病〕→「嫌犯的家人還替他說情，只是現在他不僅別想交保，又罪加一等。」理由：家屬既非加害者也非掌權者，不在嘲諷白名單；但完全不放又等於替被告消音 |

## 16. AICG 資訊圖卡規格書（附加交付件，非語體）

B5 發現的獨立產物：給 AI 生圖工具的圖卡規格。**不是語體，是可掛在任何語體上的附加交付件**——先依第 0 節決定 OS 語體，再獨立判斷「這則需不需要圖卡」，需要就在稿首加一份規格書。

- 位置詞：`大標題`／`大標題第一行`／`次標題`／`左`／`中間`／`右`／`內文N`／`標籤N`

**字數上限**：大標題 ≤10 全形字｜標籤 2–6 字｜內文每行 ≤12 字（同標籤下可並列 2–3 行）。

**規則**：
1. **變色配額：一張圖卡最多 1 個變色塊，且必須是「本則的新聞點本身」**——變色不是裝飾，是替觀眾指出重點在哪。

6. **素材標註**：AI 生成圖一律標「（圖／AI生成圖表）」或「畫面來源: AI生成示意圖」，**不可標成通訊社來源**。
