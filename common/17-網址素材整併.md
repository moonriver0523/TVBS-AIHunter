# 17　網址素材整併（韓聯社／CNA／OTH…）

> **適用**：拿到**新聞網站或 YouTube 網址**、要整理成晚班交接素材行的情形。
> 目前涵蓋韓聯社（Yonhap／연합뉴스TV）、新加坡亞洲新聞台（Channel NewsAsia, CNA），
> 以及 **`OTH`（其他網址來源，2026-09-05 新增）**：X（推特）、Instagram，或任何
> 不屬於既有站台代碼（RT／AP／NS／ENEX／ABC／CNN Newsource／韓聯社／CNA）的
> 帶 URL 素材，也包含**不是韓聯社／CNA 頻道**的獨立 YouTube 影片。
> 建立 2026-08-09（原本是 Claude共用 的一份手貼 PROMPT），**2026-08-10 收進版控**——
> 規則散在雲端硬碟就會出現「改了 repo 沒改那份、或反過來」的雙真相源問題。
>
> **一句話交辦**：見 [`scripts/s2_url_prompt.md`](../scripts/s2_url_prompt.md)。
> 那份只有一句話叫 agent 來讀本檔，**規則不重複寫在那裡**。

## 0. 這件事的定位

- **一個 URL ＝ 一則素材**（不是側錄，**會**計進檔頭則數）。
- 素材行的通用格式、括號職能、摘要 150 字上限等，**以 [`13-S2-定時掃帶.md`](13-S2-定時掃帶.md)「素材行的寫法」為母規則**；
  本檔只寫網址素材**額外**或**更嚴格**的部分。兩者衝突時以本檔為準（本檔是特例、13 是通則）。

## 1. ⛔ 絕對不要做的三件事

1. **不要改狀態檔 `{MMDD}-s2-state.json`。**
   自動掃帶每 2 小時一輪、一輪約 19 分鐘，那個檔**沒有檔案鎖**——寫入的當下若掃帶輪正在寫回，
   那幾則會**靜靜消失且不會報錯**。只寫候選檔。
2. **不要下載影片、不要存檔案。** 只要文字。
3. **不要自己 render**，也不要碰 `{MMDD}晚班交接.txt` 與 `.html`。掃帶輪會順手整併。

## 2. 交件位置

```
G:\我的雲端硬碟\Claude共用\自動掃帶系統\_待整併\{MMDD}-韓聯社CNA.txt
G:\我的雲端硬碟\Claude共用\自動掃帶系統\_待整併\{MMDD}-OTHER.txt   ← OTH 專用，另開檔，不要混進上面那份
```

`{MMDD}` ＝**今天**。**檔案已存在就 append 到最後**，不要覆蓋——同一天可能分好幾次交件；
若使用者要求「候選檔另存」，則每批改開一個新檔（如 `{MMDD}-OTHER2.txt`），不要 append 進已交出去的檔。

## 3. 素材行格式

```
======大分類======

【中主題】
小分題
YNA01 (來源 形式標) (BITE) ▎摘要▎畫面：…▎BITE：受訪者身分 姓名「引述原話」▎1:23
▎URL：https://…
```

| 欄位 | 規則 |
|---|---|
| **代碼** | 韓聯社＝`YNA`＋2 碼流水；CNA＝`CNA`＋2 碼；**OTH（其他平台）＝`OTH`＋2 碼**。**每天從 01 重編**，同一天接續，不跳號不重號。三種代碼各自獨立編號，不共用序號 |
| **第一括號 `(來源 形式標)`** | 來源寫 `韓聯社`／`CNA`；**OTH 一律寫實際平台名稱**（`X`／`IG`／`YouTube`…），不要寫「OTH」或「OTHER」——`OTH` 只是內部代碼前綴，不是要顯示的來源名。**形式標必填**，見 §4 對照表。例：`(韓聯社 SOT)`、`(CNA 現場帶)`、`(X 現場帶)` |
| **第二括號 `(BITE)`** | **有可用聲音才寫**（含 OS，見 §5）。寫了就一定要有 `▎BITE：` 段，缺一會被品質掃擋下。**只有這一個第二括號**，不准開第三個 |
| **摘要** | 一句話講完，**150 字硬上限**。超過就分句或移進畫面段。⚠️ 形式標已在第一括號，摘要不要用全形（）再標一次 |
| **▎畫面：** | **必填**。只有照片就寫「僅圖片，無動態畫面」 |
| **▎BITE：** | 見 §5。完全沒有人聲才寫 `▎無BITE。` |
| **時長 `▎M:SS`** | **網址素材一律必填**——這類素材時長看得到，不像通訊社「站方沒給就沒有」。放整行最後。真的抓不到就**留白並在回報裡列出待補**，⛔ 不要編數字、不要 `▎?`／`▎00:00` 佔位 |
| **行尾** | `▎無BITE。` 或 BITE 收尾引號 `」`，緊接時長。後面不准再拖東西 |
| **▎URL：** | **另起一行**放原始網址，讓編輯能回頭查證 |

⚠️ **不要自己加時段標記**（`△▲◇◆`）——render 依收錄時間自動補，寫了會變成兩個。

## 4. 形式標對照表（六選一，不要自創）

| 形式標 | 用在什麼 |
|---|---|
| `SOT` | 記者過音串起 **2 段以上**受訪者 BITE 的完整包裝 |
| `記者報導` | 記者過音，只夾 1 段或 0 段受訪者 BITE |
| `主播讀稿` | 只有主播棚內讀稿配畫面 |
| `現場帶` | 沒有旁白的現場畫面／典禮實況／原始素材 |
| `現場連線` | 氣象主播／記者現場連線，沒有過音包裝 |
| `專訪` | 一問一答的訪談 |

## 5. 🔑 BITE 的認定：**主播／記者 OS 也算 BITE**（2026-08-09 使用者訂）

> **理由**：這些素材是給編輯拿去用的，**只要帶子上有可用的人聲就有價值**——
> 主播或記者的過音一樣可以翻譯後配上。原本只認「受訪者談話」，
> 會讓一堆有旁白的帶子被標成 `無BITE`，編輯掃過去就跳過了。
> **同一條也適用 CNA 與 NS。**

寫法**不引句**，只標明可用（2026-08-09 使用者選定）：

```
▎BITE：主播 OS 全程可用
▎BITE：記者 OS 全程可用
```

判定順序：

| 帶子上有什麼 | 怎麼寫 |
|---|---|
| 有受訪者談話 | `▎BITE：身分 姓名「濃縮引言」`，多則用 `／` 分隔（原本的寫法，不變） |
| 沒有受訪者，但有主播／記者旁白 | `▎BITE：主播 OS 全程可用`／`▎BITE：記者 OS 全程可用` |
| **完全沒有人聲**（靜音帶、純自然音、純現場收音） | `▎無BITE。` |

⚠️ **最後一列是實質的**，不是形式：NS 的 `VO/SIL` 是靜音帶、`VO/NAT` 只有自然音
（NS 的 VO 稿是**給收訊台自己的主播讀的**，帶子上沒有旁白）——這兩種**維持 `無BITE。`**。
硬標「OS 全程可用」會讓編輯排進 rundown 才發現沒聲音，**那比漏標更糟**。

## 6. 怎麼判形式與 BITE：**讀文稿就好，不要下載影片**（2026-08-09 實測訂案）

韓聯社（연합뉴스TV）YouTube 影片的**說明欄就是完整文稿**，角色用方括號標出來。
**光看那些標記就能機械判定，一支影片都不必下載、不必看畫面。**

| 文稿裡出現的標記 | 形式 | 受訪者 BITE |
|---|---|---|
| 完全沒有 `[앵커]`／`[기자]`，全文約 200–350 字 | `主播讀稿` | 無 → 寫 `主播 OS 全程可用` |
| 有 `[기자]` ＋ `[姓名 / 職稱]` 講者標記 **2 組以上** | `SOT` | 有，照抄那幾組 |
| 有 `[기자]` ＋ 講者標記 **1 組** | `記者報導` | 有，照抄那組 |
| 有 `[기자]`，**0 組**講者標記 | `記者報導` | 無 → 寫 `記者 OS 全程可用` |
| 有 `[캐스터]`／`[현장연결]`，沒有 `[기자]` | `現場連線` | 依實際；沒有就寫 `主播 OS 全程可用` |

**`[姓名 / 職稱]` 就是受訪者**，例：`[이재명 / 대통령(지난 6일)]`、
`[강다연 / 기상청 예보분석관]`、`[이정림 / 서울 종로구]`（一般民眾標居住地）。

⚠️ **實測驗證過（0809，17 則全中）**：有受訪者的 5 則，文稿裡**每一則都有講者標記**；
沒有講者標記的 12 則**確實都沒有受訪者談話**。所以「文稿沒標＝真的沒有受訪者」。
**⛔ 不要為了湊 BITE 去猜或編一個引言**——那會把假引言送進編輯要用的交接單。

⛔ **不要為了判形式去下載影片或逐支點開看畫面**，那是無謂消耗。

## 6b. `OTH`（X／IG／其他）專屬：通常沒有現成文稿，判不準就照 §11 停下來問

韓聯社／CNA 能「只讀文稿就機械判定」，是因為 YouTube 說明欄固定放完整逐字稿。
**X／Instagram 貼文通常沒有這種東西**——說明文字多半只是新聞摘要或官方聲明，
不是逐字稿，**不能拿摘要文字硬套成 `▎BITE：` 引言**。

- 有明確逐字稿／官方新聞稿附上引述 → 可比照 §6 表格判斷。
- 沒有逐字稿、且看不出畫面裡有沒有可用人聲 → **形式標依畫面內容判**（例：官方單位
  直接發布的原始救援畫面、沒有旁白包裝＝`現場帶`），**BITE 與時長留白**、
  在回報裡列「待補（需實際看片確認）」，⛔ 不要用摘要文字杜撰引言、不要編時長。
- 判斷不出來（含看不出來源帳號是否為官方／權威帳號）就照 §11 停下來問，不要自己猜。

📌 **取得說明欄的做法**：YouTube 現在會擋 bot（`Sign in to confirm you're not a bot`），
yt-dlp 直接被拒。可用的是**在 youtube.com 同源用 `fetch('/watch?v=…')` 抓 HTML、
取 `"shortDescription"` 欄位**；時長則從**頻道 `/videos` 列表頁**讀卡片上的時長標籤
（`a[href*="watch?v="]` 的祖先卡片，innerText 第一行就是時長），
**不要逐支點開影片頁**——會慢而且容易被擋。

## 7. 大分類：只能用這 16 個，順序固定

第一格是機動的「時效性特殊」（隨當天大事換），其餘 15 格固定：

```
大陸／關稅／美伊／中東／烏俄／美國／政治／財經／社會／天氣／體育／科技／娛樂／話題
```

**先看今天的 `{MMDD}晚班交接.txt` 裡已經有哪些【中主題】**，同一件事掛既有的，
不要另開名字相近的新中主題（例如已有【颱風海豚】就不要再開【海豚颱風】）。

## 8. 用字規則（台灣電視新聞）

- **一律繁體中文**，不能出現簡體字。
- 指涉臺灣這個地方的「台」寫**「臺」**；電視台／平台等本義用法、台積電／台鐵等專有名詞維持「台」。
  完整對照表與例外（專有名詞、逐字引語、不溯及既往）見 [`00-寫稿通則.md`](00-寫稿通則.md) 的「臺／台 用字」節——**那份是唯一來源**，這裡只是摘要。
- 譯名用台灣慣例：**川普**（不是特朗普）、**普欽**（不是普京）。
- 單位換算：外幣→**新台幣**（括號附註）、℉→℃、英里→公里、英尺→公尺。
- 專有名詞**首次出現**夾原文，例：`釜山（Busan）`。

⚠️ **`CNA` 專指新加坡亞洲新聞台（Channel NewsAsia），不是中央社**（2026-08-09 使用者確認）。
第一版寫成「中央社」，交件回來的卻是新加坡國慶——**同一個縮寫兩家媒體**，內容對了但定義沒對上。
日後若要收中央社，**必須另給前綴**（例如 `CNAT`），不可共用 `CNA`。

## 10. 交件後回報

在對話裡回一句就好：

```
已寫入 _待整併\0809-韓聯社CNA.txt：韓聯社 3 則（YNA01–03）／亞洲新聞台 1 則（CNA01）
```

另外把**需要人工決定的事**條列出來（新開的中主題、時長待補、判斷不確定的）。

## 10b. T／C 標籤：**你來判**（2026-08-25 改；原本寫「你不用下」是錯的）

> 📌 **這一節是寫給你——交件端**（拿網址整理成素材行的這個 agent）。
> 2026-08-25 之前這裡寫「T/C 由掃帶輪整併端下、不是你的工作」，
> 使用者當天改判：**讀過內容的是你，就由你判**。掃帶端只負責貼上。

晚班交接網頁另有一條 **T（議題）／C（地緣）** 軸，與大／中／小三層**並行**，
不影響素材行、不影響大分類歸位。

#### 怎麼輸出：檔尾附一行可直接貼的字串

⛔ **不要寫進素材行**，也不要寫進任何 `▎` 欄位——素材行有既定格式，
多寫的東西會被下游的品質掃當成壞行。改成在交件檔**最後**附一個區塊：

```
── T／C（掃帶端直接貼進 set-tc，⛔ 不要貼進晚班交接.txt）──
YNA01=社會/南韓;YNA02=財經/南韓,美國;CNA01=政治/新加坡;CNA02=天災天氣/東南亞
```

格式就是 `id=T1,T2/C1,C2`，分號分隔、`/` 左邊是 T 右邊是 C，各自可多選。
⚠️ **T 最多 3 個、預設 1 個**（機動 T 不佔格）：多掛一個要能說出
「拿掉它這則就分類錯了」，第 4 個起掃帶端下 `set-tc` 時會被**整則退回**。
判不出來的**留空不要寫那一則**——硬掛一個錯的比留空更糟，缺的那則掃帶端
會在覆蓋率閘門看到。

#### 名單只認 [`13f`](13f-S2-大分類與各站規則.md)「議題 T／地緣 C」那兩張表

T 11 類／C 21 類，⛔ 不在表裡的名稱會被退件。三個最容易錯的形狀：
- **專項獨佔**：以色列／伊朗有專項就**不掛**中東
- **專項＋區域**：泰國／新加坡掛專項時**東南亞也要掛**
- **併入區域**：墨西哥掛中南美（沒有墨西哥這一格）

#### 來源預設 C

| 來源 | 預設 C |
|---|---|
| `YNA` 韓聯社 | **南韓** |
| `CNA` 新加坡亞洲新聞台 | **新加坡,東南亞**（專項＋區域，兩個都要） |
| YouTube（非韓聯社／CNA 頻道） | **無預設**，一律照內容判 |
| `OTH`（X／IG／其他任意 URL） | **無預設**，一律照內容判 |

🔴 **「預設」是起點不是終點。** 先讀你剛整理完的那則講什麼，內容明顯指向
他處就照內容判——你已經讀過全文了，這一步幾乎不花額外成本：
- 韓聯社報「川普關稅衝擊南韓車廠」→ C 掛 **南韓,美國**，T 掛 **財經**
- CNA 報「印尼火山噴發」→ C 掛 **東南亞**，**不是**新加坡

⚠️ **T（議題）沒有預設**，一律照內容判。

#### 機動 T

使用者當天可能開了機動 T（例：`颱風`）。**你不必自己查**——有的話會寫在
交辦訊息裡；沒寫就當沒有，⛔ 不要自創。機動 T 是**加掛**：颱風素材寫
`YNA03=颱風,天災天氣/南韓`，不是只寫「颱風」。

## 11. 遇到這些狀況要停下來問，不要自己猜

- 網址打不開、或內容不是新聞（首頁、專題列表、付費牆）
- 同一則新聞在今天的交接單裡**已經有通訊社版本**（可能重複，要問要不要收）
- 判斷不出該掛哪個大分類（尤其橫跨兩類的，例如「中國＋財經」）
