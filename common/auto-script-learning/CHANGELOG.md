# 自動寫稿學習機制變更紀錄

## 2026-07-16 — v1.0

- 建立根目錄代理入口 `AGENTS.md`，要求其他AI代理先讀持續校稿索引。
- 建立規則成熟度：`NEW / REPEATED / CONFIRMED / PROMPT / RETIRED`。
- 建立案例索引、案例模板與首筆案例 `2026-07-16-川想擴戰2200`。
- 補存首筆案例的使用者完整修改稿，並將AI初稿、使用者稿、差異證據與規則萃取互相連結。
- 將CNN六碼素材BITE盤點、指定長度優先、NS納入計時及明確授權後可使用最新網路資訊，寫入自動寫稿核心流程。
- 登錄強現場開場、NS節奏、四層深度分析、CNN分析型BITE及因果敘事重排等候選方法，保留後續稿件驗證。
