## 每題輸出

依候選 json 的順序（已經照分數排好，不要自己重排），每題輸出六個欄位：

1. **稿頭**：3–6 字短標題，濃縮新聞切角（`common/11`「稿頭」節），不是逐字新聞
   標題，不套固定字庫。
2. **角度**：一句話，這題現在該怎麼切、為什麼值得做（不是複述摘要）。
3. **建議形式**：三選一，判準：
   - **CTV**（CNN Newsource 單一 story 全流程寫稿，`cnn/01`）：`ctv_ids` 非空。
   - **SOT**（一般外電配稿、有引言）：`ctv_ids` 為空，且這題 ≥2 個不同來源
     （看 `items[].src`）且至少一則 `bite=true`。
   - **BS**（主播稿，無合適引言／單一來源）：其餘情況。
4. **素材行**：照 `common/11`「素材代碼」＋「短摘要」＋「選用標記」規則，每則
   一行 `{素材代碼} ({備註}) [(BITE)] {摘要}▎畫面：{逐項}▎BITE：「{濃縮引言}」`
   或 `▎無BITE。`。**摘要直接沿用 `get --id` 查回來的 `fields.summary`**，不用
   重新改寫（候選 json 沒有摘要全文，須查完才能寫這行）。同一題多則素材照
   `common/11`「素材代碼」節的 ` / ` 相接規則。
5. **缺什麼**：直接沿用候選 json 的 `missing`（沒有就寫「無」）。
6. **分派建議**：只填**角色**（例如：外電編譯／連線／體育／影音），
   **⛔ 不准填人名**——D16 裁決記者名單尚未提供，AI 不能自創分派對象。
