## 怎麼看

只要三個指令，**不要逐則重讀內文**（那要 4–5 萬 token，是這一步的 8～10 倍）：

```
python scripts/s2_state.py list-topics --subs
python scripts/s2_topic_review.py --file "…/{MMDD}-s2-state.json"
python scripts/s2_topic_dedupe.py --file "…/{MMDD}-s2-state.json"
```

看名稱層就夠了。要找的是這四種（0810 實例都是光看名稱就該起疑的）：

1. **同一地點／事件散在不同中主題**
   例：「卡利市長證實建物倒塌受困」掛在【強震速報】，但同時存在【卡利災情】。
2. **掛到錯的地點底下**
   例：「佩雷拉教堂立面坍塌」掛在【卡利災情】——佩雷拉不是卡利；
   「馬尼薩雷斯教堂鐘塔倒塌」掛在【波哥大災情】——也不是波哥大。
3. **同義不同名的中主題／小分題**
   例：【高爾夫】＋【高球】、「梅西父喪」＋「美斯家事」（港譯台譯，零共同字，
   機器抓不到，**只有你看得出來**）。
4. **中主題放錯大分類**（`list-topics` 會自己提示一部分，其餘靠你看）。

只認兩種指令行，其餘（空行、`#` 註解、說明文字）都會被略過：

```
MOVE  {素材id}={大分類}/{中主題}/{小分題}
ORDER {大分類}={中主題1};{中主題2};…
```

⚠️ **一行一筆**。素材 id 含空格（側錄是 `CNN 08-10 224714`），不要自己拼分號字串。
✅ **建議寫理由**：在指令行上方用 `#` 寫一句為什麼，方便掃帶輪與人覆核。
📌 `ORDER` 用來把同一國家／類似主題排在一起；沒列到的中主題會自動插到名稱相近的旁邊，
所以**不必把整份順序寫完**，只列你想釘住的。
