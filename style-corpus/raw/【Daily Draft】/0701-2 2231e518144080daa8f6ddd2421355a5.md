這部影片深入探討了冰毒（甲基安非他命）的禍害，揭露其在全球範圍內造成的毀滅性影響，包括嚴重的成癮問題、龐大的販運網絡以及危險的生產過程。影片結合了多位毒品受害者的親身經歷、執法機構的行動，以及對全球毒品危機的深刻洞察。

影片中，多位曾受冰毒所苦的人士分享了他們的悲慘故事，凸顯了毒品對個人及其家庭造成的巨大傷害：

- **生命受創** : 許多成癮者因毒品而失去家庭、工作，甚至將孩子置於危險境地。有人從14歲開始沾染毒品，毒癮長達19年，最終因犯罪入獄，生活被徹底摧毀。
- **身心俱疲** : 毒品對身體、情緒和心理造成難以逆轉的嚴重損害，使受害者深陷其中而難以自拔。
- **漫長康復路** : 康復之路艱辛漫長，需要強大的意志力和全面的支持。影片中不乏成功戒毒者，他們在康復後努力將愛與希望傳遞給仍在掙扎的人，並積極推動「一次都不要碰」等提升意識的活動。家庭支持對戒毒成功至關重要，但許多情況下，家庭關係已因毒品而破裂。

冰毒因其易於生產的特性，已成為全球犯罪集團的主要獲利來源：

- **生產簡便** : 合成毒品（如冰毒）的生產門檻低，不需農田，只需實驗室、化學家、化學品以及執法單位的庇護。生產地點遍及高層公寓、鄉村地帶、工業建築、住宅甚至移動式實驗室。
- **全球網絡** :
    - 阿富汗的塔利班因選擇性打擊，使得冰毒成為主要收入來源。
    - 緬甸因化學品充足、化學家專業及執法薄弱，成為合成毒品生產的溫床。
    - 加拿大也從毒品消費國轉變為冰毒和芬太尼的出口國，將毒品販運至國際市場。
    - 有犯罪組織將總部設在海外（例如聯合國幫派將總部設在越南胡志明市），並利用加拿大法律對高層犯罪分子執法較為寬鬆的特點。
- **高額利潤** : 國際販毒集團每年可帶來數十億美元的收入，其規模甚至超過一些小型國家的經濟總量。美國大麻合法化也促使黑市轉向利潤更高的合成毒品生產。

毒品氾濫對社會治安及公共衛生造成了嚴峻考驗：

- **執法困境** :
    - 在不列顛哥倫比亞省（BC省），硬性毒品非刑事化試點後，執法單位對持有毒品的管制權力受限，導致毒品被用作交易芬太尼的貨幣，進一步助長幫派勢力。
    - 警方在處理毒品實驗室時面臨高風險，需應對劇毒化學品；繳獲的毒品數量可達數百萬劑，即使微量（如2毫克）也足以致命。
- **危害數據** :
    - 澳洲的冰毒零售價奇高，西澳地區的年交易額可達9億美元，顯示其驚人利潤。
    - 澳洲透過廢水檢測等數據追蹤毒品使用趨勢，發現冰毒在鄉村地區消耗量極高，人均消費量位居世界第二，僅次於紐西蘭。
- **社會破壞** : 毒品導致犯罪率飆升（包括盜竊和自殺）、家庭破碎、街頭暴力及無家可歸者問題惡化，對全國各地社區造成了深遠影響。

面對日益嚴峻的毒品問題，各國積極推動康復與支持措施：

- **視為病人** : 需將毒癮者視為病人而非罪犯，提供專業的康復治療。巴基斯坦目前設有六個正規康復中心，致力於此。
- **提供支持** : 康復中心成為許多無家可歸或與家人斷絕關係的成癮者的「地址」，為他們提供必要的住所和支持。
- **社區行動** : 透過「反冰毒遊行」等社區活動，提高公眾對冰毒危害的意識，呼籲社會各界共同對抗毒品所帶來的流行病。
