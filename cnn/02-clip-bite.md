# CNN掐Bite

本規則是 [`掐BITE助手`](../common/07-bite-assistant.md)（原「指定掐Bite」，已升級為獨立流程）的延伸情境：當 CNN Newsource 的 `SUPERS`／`SOT` 結構文稿，或 AP 式 `SHOTLIST`／`SOUNDBITE` 編號清單完全沒有 TC 時，用本流程補上句子級 TC。

除本文件記載的 TC 定位方法外，輸出格式、SB 命名慣例、中文翻譯、素材查找、不剪片、不上傳及不另存文字檔等規則，全部沿用「掐BITE助手」（含其省 Token 核心：先選句再找 TC、不把 ASR 全文貼進對話）。

**Rollback：** 省 Token 改寫前舊版見 [`../_archive/cnn/02-clip-bite.pre-token-saving-2026-07-20.md`](../_archive/cnn/02-clip-bite.pre-token-saving-2026-07-20.md)。

## 省 Token 執行備註

1. **先鎖定官方文稿中的目標句**，再跑／查 ASR；不要先整支片當閱讀材料。
2. **同一支素材 `video_analyze` 只一次**；ASR 過長時落地存檔（例如旁路 `{檔名} ASR.txt`），後續多個 Bite 共用，**不要**把整份 ASR 貼進對話。
3. 對目標句取 5–10 個關鍵字在 ASR 中命中後，**只核對前後約 5 秒** 決定起訖。
4. 對話最終只輸出五行 SB；不附完整官方稿或 ASR。

## 觸發條件

使用者提供一個已存在於下列位置的 CNN／AP 素材檔名，同時貼上該素材的官方文稿，並要求掐出一句或多句 Bite：

1. `G:\我的雲端硬碟\Claude共用\`
2. 「掃帶歐印萬」資料夾（不是名稱含 `v2` 的資料夾）

## 1. 以官方文稿為逐字權威來源

官方文稿中 `SOUNDBITE`／`SOT` 的英文逐字內容，是最後輸出的唯一英文原文來源，必須逐字照抄。

`video_analyze` 產生的語音辨識文字只用來尋找時間位置，不可取代或修正官方文稿。ASR 可能出現同音或近音錯字，例如把 `bend` 聽成 `ban`；即使 ASR 與官方文稿不同，最後仍以官方文稿為準。

## 2. 用 video_analyze 取得相對 TC

對找到的本機素材檔案呼叫 `video_analyze`，並將 filters 設為：

```text
transcription: true
```

取得整支影片逐句、精確到秒的語音辨識結果及每句 `start`、`end` 時間戳記。同一支素材只需分析一次；保留完整分析結果（可落地存檔）供後續一個或多個 Bite 共用，不要重跑，也不要整份貼進對話。

`video_analyze` 時間戳記的精確度是可用上限，不宣稱比分析結果更精確。

## 3. 將官方文稿與 ASR 結果比對定位

先從官方文稿鎖定要引用的句子，取關鍵字後對照 `video_analyze` 結果中語意相同或相近的句子：

- 取第一個對應句的 `start` 作為 Bite 相對起點。
- 取最後一個對應句的 `end` 作為 Bite 相對終點。
- 命中後只核對該段前後約 5 秒即可，不必重讀整份 ASR。
- ASR 有錯字但語意及前後文可確認為同一句時，仍可用來定位；英文輸出不得照抄 ASR 錯字。
- 若無法可靠判定對應句，不自行猜測 TC，應明確告知使用者無法確認。

## 4. 套用檔名 TC offset

檔名前6碼的解析、有效性判斷、8碼檔名處理及相對TC換算，全部依 [`TC offset檔名慣例`](../common/02-tc-offset-filename.md)。把換算後的真實起訖時間用於最後輸出；本文件不另行維護一份重複規則。

## 5. 選擇 Bite

- 使用者指定句子時，定位並輸出指定的一句或多句。
- 使用者只貼官方文稿、要求自行挑選時，依「有新聞價值、有衝突性」原則挑選。
- 同一素材需要追加更多句時，直接沿用第一次的完整 `video_analyze` 結果，不重新呼叫分析。

## 6. 輸出

交付給使用者的內容是純文字五行，**不要包在 code fence 裡**（本文件與 [`掐BITE助手`](../common/07-bite-assistant.md) 內的 code 區塊只是格式示意）。格式與欄位規則沿用掐BITE助手的5行SB格式：SB → 職稱姓名 → 中文翻譯 → TC欄位 → 英文原文。若素材本身有 `#編號`，TC欄位為 `#{編號} {TC起}-{TC訖}`；否則為純6碼無冒號起訖時間。

```text
SB
{中文職稱} {英文姓名}
{中文翻譯}
{TC欄位}
{官方文稿英文原文逐字}
```

**英文原句不加任何引號**（不用 `""` 也不用 `“”`），與 [`掐BITE助手`](../common/07-bite-assistant.md)、[`自動寫稿(CTV)`](01-auto-script-writing.md) 一致。英文逐字必須來自使用者貼上的官方文稿，不得使用 `video_analyze` 的 ASR 文字替代。
