# CNN掐Bite

本規則是 [`掐BITE助手`](../common/07-bite-assistant.md)（原「指定掐Bite」，已升級為獨立流程）的延伸情境：當 CNN Newsource 的 `SUPERS`／`SOT` 結構文稿，或 AP 式 `SHOTLIST`／`SOUNDBITE` 編號清單完全沒有 TC 時，用本流程補上句子級 TC。

**開始前必讀**：[`common/00-寫稿通則.md`](../common/00-寫稿通則.md)（**SB 五行格式與 TC 欄位寫法的唯一規格**）、[`掐BITE助手`](../common/07-bite-assistant.md)（找 TC 的來源優先序、先選句再定位、素材查找、不剪片不上傳不另存文字檔）。本文件只寫「官方文稿完全沒有 TC」時的比對定位法，其餘不重述。

**Rollback：** 省 Token 改寫前舊版見 [`../_archive/cnn/02-clip-bite.pre-token-saving-2026-07-20.md`](../_archive/cnn/02-clip-bite.pre-token-saving-2026-07-20.md)。

## 省 Token 執行備註

1. **先鎖定官方文稿中的目標句**，再跑／查 ASR；不要先整支片當閱讀材料。
2. **同一支素材 `video_analyze` 只一次**；ASR 過長時落地存檔（例如旁路 `{檔名} ASR.txt`），後續多個 Bite 共用，**不要**把整份 ASR 貼進對話。
3. 對目標句取 5–10 個關鍵字在 ASR 中命中後，**只核對前後約 5 秒** 決定起訖。
4. 對話最終只輸出五行 SB；不附完整官方稿或 ASR。

## 觸發條件

使用者提供一個已存在於下列位置的 CNN／AP 素材檔名，同時貼上該素材的官方文稿，並要求掐出一句或多句 Bite：

1. `G:\我的雲端硬碟\Claude共用\`
2. 「掃帶歐印萬」資料夾（不是名稱含 `v2` 的資料夾，跳過裡面的 `Archive` 子資料夾——都是舊資料）

## 本流程專屬：官方文稿 × ASR 的比對定位法

> 本節若與 [`掐BITE助手`](../common/07-bite-assistant.md) 不一致，**一律以 `07` 為準**。

這是本文件唯一不在 [`掐BITE助手`](../common/07-bite-assistant.md) 的內容——當官方文稿有逐字但**完全沒有 TC** 時，怎麼把文稿句子對到影片時間軸：

1. 先從官方文稿鎖定要引用的句子（依 `07` 的「先選句再找 TC」）。
2. **素材是YouTube URL時，先依 `07` 第4項找YouTube官方/自動字幕，不要跳過直接跑 `video_analyze`**——2026-08-24「CNN台獸」案例證實 `video_analyze` 對8分鐘級長片的分段轉錄會有漸進式TC漂移（同一句引言兩次轉錄結果最多差24秒，影片後段甚至差近60秒），字幕檔或畫面燒錄字幕才是可靠的時間軸來源。真的沒有字幕可用時，才對本機素材檔跑 `video_analyze`（`filters: {transcription: true}`），取得逐句 `start`／`end` 時間戳。**同一支素材只跑一次**，結果可落地存檔供多個 Bite 共用，但**輸出前用畫面燒錄字幕或第二次轉錄交叉核對過**，不可單信一次轉錄結果（見 `07` 的漂移警示章節）。
3. 取關鍵字在 ASR 結果中找語意相同或相近的句子：
   - **起點**＝第一個對應句的 `start`；**終點**＝最後一個對應句的 `end`。
   - 命中後只核對該段前後約 5 秒即可。
   - ASR 有錯字但語意及前後文可確認為同一句時，仍可用來定位。
   - 若無法可靠判定對應句，**不自行猜測 TC**，明確告知使用者無法確認。
4. **英文逐字一律以官方文稿為準**，`video_analyze` 的 ASR 文字只用來定位時間，不可取代或修正官方文稿（ASR 常有同音錯字，例如把 `bend` 聽成 `ban`）。ASR 時間戳的精確度是可用上限，不宣稱比它更精確。

## 4. 套用檔名 TC offset

檔名前6碼的解析、有效性判斷、8碼檔名處理及相對TC換算，全部依 [`TC offset檔名慣例`](../common/02-tc-offset-filename.md)。把換算後的真實起訖時間用於最後輸出；本文件不另行維護一份重複規則。

## 5. 選擇 Bite

- 使用者指定句子時，定位並輸出指定的一句或多句。
- 使用者只貼官方文稿、要求自行挑選時，依「有新聞價值、有衝突性」原則挑選。
- 同一素材需要追加更多句時，直接沿用第一次的完整 `video_analyze` 結果，不重新呼叫分析。

## 6. 輸出

五行 SB 格式與 TC 欄位寫法依 [`common/00-寫稿通則.md`](../common/00-寫稿通則.md)。本情境素材通常無 `#編號`：CNN 六碼側錄用 `CNN {6碼起}-{6碼訖}`，其他無編號素材用純起訖時間。交付給使用者的內容是**純文字五行，不要包在 code fence 裡**。

```text
SB
{中文職稱} {英文姓名}
{中文翻譯}
{TC欄位}
{官方文稿英文原文逐字}
```

**英文原句不加任何引號**（不用 `""` 也不用 `“”`），與 [`掐BITE助手`](../common/07-bite-assistant.md)、[`自動寫稿(CTV)`](01-auto-script-writing.md) 一致。英文逐字必須來自使用者貼上的官方文稿，不得使用 `video_analyze` 的 ASR 文字替代。
