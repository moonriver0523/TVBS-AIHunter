## 觸發

使用者說「自動寫稿(業配)」「Advertorial」「廣編」並給 SLUG（或案件資料夾）時啟動。  
**不明確下令不跑**（與 SOT 相同）。  
稿名結尾「準」仍走準連，不走本流程。

## 輸入

案件資料夾（或對話交付後立刻落到落檔路徑）必備三類：

| 輸入 | 檔名慣例 | 角色 |
|---|---|---|
| 業配需求單 | `{SLUG} 業配需求單.txt` | **呈現必守**：時長、必講／禁講、品牌用語、畫面／BITE 指定、其他剪輯要求 |
| 官方新聞稿 | `{SLUG} 官方新聞稿.txt`（若來源是 PDF／Word／郵件，盤點前先轉成這份 txt） | **事實基礎**：產品名、數字、時程、說法。優先於素材口白與模型背景知識 |
| 散裝影音 | 原檔名可保留 | 可能多檔、**無編號、無 shotlist** |

缺需求單或官方新聞稿 → **停問**，不盤點、不寫稿。

事實衝突：需求單指定的呈現 vs 官方新聞稿的數字／用詞 → 停問。需求單管「怎麼呈現」，官方新聞稿管「事實對不對」；需求單若寫了與新聞稿矛盾的事實，以停問為準，不擅自選邊。

## 落檔

```
G:\我的雲端硬碟\Claude共用\業配自動寫稿測試\{SLUG}\
```

內含：需求單、官方新聞稿、原影片（可維持原檔名）、`{SLUG} 素材清單.txt`、各檔 ASR、`{SLUG} 完成文稿.txt`、製片中間產物、`{SLUG} 完成帶.mp4`。

## 前置盤點（寫稿前必做）

把散裝帶編成 SOT 能吃的 `#XX`。產出 `{SLUG} 素材清單.txt`，**不強制改名原片**。

步驟：

1. 列出資料夾內全部影音。
2. 每支最多一次 `video_analyze`（`transcription: true`）；結果落地 `{原檔名} ASR.txt`（或詞級 json，供後續 locate_sb 重用）。
3. 依 ASR／聽感標每支（或每段）：**BITE**（有可掐人聲）／**B-ROLL**（純畫面或環境音）／**混合**。
4. 依**原檔名升冪**編 `#01` 起（同一順序重跑編號不變）。一句可用畫面說明。BITE 另寫講者（能辨識才寫）＋一句內容。需求單若指定順序，以需求單為準。
5. 需求單指定的必用畫面／必用 BITE 必須對到某個 `#XX`；對不上 → **停問**，不硬寫。
6. ASR 失敗：該檔標「待人工」，繼續其他檔；若需求單點名的檔失敗 → 停問。

素材清單欄位（一行一檔，精簡、不貼 ASR 全文）：

```
#XX｜原檔名｜BITE/B-ROLL/混合｜可用畫面一句｜BITE 一句（無則「無」）｜時長｜限制／備註
```

另附對照表：`#XX` → 原檔完整路徑。製片只讀這張表，不靠檔名裡的編號。

### 解析（`sot_common.py`，對應 CTV 的 `ctv_common.py`）

`load_script` 讀 SOT 完成稿，產出與 CTV 相同的 `blocks`：

```
[{"bar": 1, "os": [口白行…], "sb": {…} 或 None}, …]
```

- `bar`＝OS 區塊序（被 SB 切開），不是 CTV 字卡 BAR。
- **口白行**：去掉 `#XX TC…`、`畫面來源`、`NS …`、`==AICG==` 及其下一行圖卡字（圖卡行若即 OS，需求單沒說要唸則不唸；與 SOT `P-048` 衝突時以需求單為準，無指示則跟 SOT：該行要唸、但製片第一版不燒圖卡）。
- 每個 OS 區塊另保留 `shots: [{"num": "01", "tc": "0005", "desc": "…"}, …]` 供剪接。
- SB 解析沿用 `validate_sot` 的 SOT 五行／TC 文法；`#XX` 用素材清單對到原檔。

### locate_sb

- 對完成稿裡出現的每個 SB，在**該 `#XX` 檔**上精裁。
- **重用盤點 ASR／詞級時間戳**，同一檔不重跑 transcription。
- 輸出仍為 `sb_spans.json`（起訖秒數＋中文錨點），另記 `file`／`#XX`。

### synth_os

從 CTV 複製。只唸 `os` 口白行。2–3 行一組、犧牲字、int16、覆蓋率門檻全部沿用 `production/01` 與 `09`。

SOT 口白可能超過 CTV 14 字／行：配音以稿面行為準（可長行）；上字再折行。

### build_video（本變體唯一重寫）

- **SB**：從對應檔依 `sb_spans` 切（頭 -0.10、尾 +0.30），不做 VAD 二次裁。
- **OS**：該區塊 `shots` 依稿序接上，**總長度＝該段配音時長**。
  - 每標注從該檔起點 TC 播到：下一標注開始、或本檔 EOF、或配音用完。
  - 多標注依序切；單一標注則從起點播滿配音。
  - 畫面總長 < 配音 → **停**（不循環、不 `atempo>1.05`）。
- 禁止把 SB 時間區間拿去當 B-roll。
- 輸出規格與 CTV 相同：1920×1080、`-t 音訊長`、不用 `-shortest`。
- `--source` 不再要一支母帶；改讀素材清單。若仍傳 `--source` 則忽略並警告。

### make_subs / final_check

從 CTV 複製。硬字幕／BAR／SUPER 邏輯沿用；**OS／SB 中文上字按 14 全形字折行**（即使 SOT 稿面更長）。終檢 exit 0 才可交。

## 資料流

```
需求單 + 官方新聞稿 + 散裝影音
        │
        ▼
   盤點（每片一次 ASR）→ {SLUG} 素材清單.txt（#XX→原檔）
        │
        ▼
   寫稿（規則＝06 副本）→ {SLUG} 完成文稿.txt
        │                    validate_sot --mode sot
        ▼
   locate_sb（重用 ASR）→ sb_spans.json
   synth_os             → os/*.wav
   build_video（多來源）→ assembled.mp4
   make_subs            → {SLUG} 完成帶.mp4
   final_check          → exit 0 才交
```
