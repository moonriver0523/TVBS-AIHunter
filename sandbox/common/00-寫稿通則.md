# 寫稿通則（跨流程）

所有會產出文字成品的流程（自動寫稿SOT／自動寫稿CTV／外電掃帶入庫／掐BITE助手）一律套用本文件。各流程的**輸出結構、字數上限、譯名標注格式、檔名規則**都不在這裡定義——那些是流程特有的，見各自的流程文件。

## 1. 版權原則

- 摘要、完成文稿、段落主題總覽等**一律為原創改寫**，不是逐字翻譯或複製外電稿件。
- **只有明確標示來源的簡短 BITE／SB 引言可以逐字引用**，其餘旁白（OS）皆為改寫。
- **不要在對話中逐字貼出完整外電稿件內文**（shotlist／script／Storyline 全文）。使用者要求特定內容時，摘要或描述結構，僅在必要時引用簡短片段。
- 官方完整稿件（`原始文稿.txt` 等）的存檔屬**內部參考副本，非對外散布**。
- 完整逐字轉錄整支母帶內容不可行；只有明確指定的引言／BITE 才逐字輸出。

## 2. 單位與數值換算

原文出現以下單位時，一律在中文後方括號附上換算值：

| 原文單位 | 換算 |
|---|---|
| 金額（美元等） | 附新台幣換算 |
| 華氏（°F） | 換算攝氏（°C） |
| 英里 | 換算公里 |
| 英尺／碼 | 換算公尺 |
| 風速 | 換算蒲氏風力級數 |
