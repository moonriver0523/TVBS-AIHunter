# 外電批次下載(RT)

當使用者一次提供多筆「目標檔名＋Edit No.」清單，要求下載 Reuters 原始素材、改名並上傳共用資料夾時，使用本規則。

本流程與 [`自動掐SO(RT)`](03-auto-clip-so.md) 不同：不剪片、不找 TC、不找引言，只將多支 Reuters 原始素材整支下載、依清單改名並上傳。

## 觸發格式

使用者提供一串類似下列格式的清單，並要求下載、上傳共用及套用相對應檔名：

```text
{檔名前綴} #{序號} RT{Edit No.}
```

例如：

```text
封鎖開始 1200 #04 RTV7836
```

此筆應解析為：

- 目標檔名：`封鎖開始 1200 #04 RT`
- Edit No.：`7836`

清單尾端若以 `RT` 或 `RTV` 緊接 Edit No.，數字部分均視為 Edit No.；目標檔名則依使用者格式保留至 `RT`，不把 Edit No. 放入檔名。

## 開始前：解析及檢查清單

開始任何搜尋或下載前，先逐筆解析出：

- 目標檔名
- 序號
- Edit No.

檢查整份清單是否有重複 Edit No.。若有重複，必須先列出重複項目並向使用者確認是否為打字錯誤；在使用者確認前不開始下載，也不自行假設要丟棄或保留哪一筆。

## 每一筆的處理流程

### 1. 搜尋 Edit No.

前往 `reutersconnect.com`，切到 **Video** 分頁，以該筆 Edit No. 搜尋素材。

### 2. 核對搜尋結果主題

Edit No. 可能撞號到完全不相關的舊新聞，不可直接選擇第一筆結果。必須核對搜尋結果的標題、事件與主題，確認符合這一批清單的整體主題脈絡後才開啟。

若結果無法與主題脈絡可靠對應，停止該筆並回報使用者，不自行猜測。

### 3. 記錄完整 Restrictions

進入素材詳情頁，讀取並記下右側 **Restrictions** 面板的完整限制內容，供最後彙整及警示使用。

### 4. 下載原始素材

點擊 **Download**。預設選擇 **HD 60fps MP4**，不需逐筆詢問格式。

### 5. 輪詢確認下載完成

用 PowerShell 輪詢 `D:\Downloads`，確認新下載檔案已完成且檔案大小穩定，再進行複製。

- 不以檔名出現作為下載完成的唯一判斷。
- 檔案仍持續增大時，繼續等待。
- 若多次輪詢大小均未變化，但下載仍未正常完成或檔案仍是暫存狀態，視為下載卡住。
- 卡住時回報使用者，不無限重試。

### 6. 改名並上傳共用資料夾

將確認下載完成的檔案複製到：

```text
G:\我的雲端硬碟\Claude共用\
```

複製時改成該筆解析出的目標檔名，並保留正確的影片副檔名。除非使用者另有指示，不改動 `D:\Downloads` 的來源檔案。

### 7. 追蹤批次進度

筆數較多時可用 Task 追蹤每一筆的狀態，例如：待搜尋、下載中、已上傳、卡住、需確認。完成或記錄該筆狀態後繼續下一筆，不因單筆失敗遺漏其餘項目。

## 全部完成後的輸出

輸出彙整表：

| 檔名 | Edit No. | 限制重點 |
|---|---:|---|
| {目標檔名} | {Edit No.} | {Restrictions 摘要} |

對不尋常的限制加上 `⚠️` 明確提醒，尤其包括：

- 整個地區或國家禁用
- 特定媒體、平台或客戶黑名單
- 其他會影響 TVBS 使用或播出的重大限制

一般限制可在表內摘要；完整 Restrictions 內容必須在處理過程中留存，不可因摘要而漏掉重要條件。
