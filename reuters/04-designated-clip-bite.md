# 指定掐Bite

當使用者以「指定掐Bite」呼叫，或提供既有素材／原始外電文稿並要求找出一段 Bite 的 TC 與雙語逐字時，依本規則執行。

本流程與 [`03-auto-clip-so.md`](03-auto-clip-so.md) 的「自動掐SO(RT)」不同：素材已存在本機或雲端，不上 Reuters Connect 搜尋或下載；只在對話中輸出指定格式的文字，不使用 ffmpeg、不剪片、不將檔案上傳雲端，也不另存 `.txt`。

## 1. 確認素材來源

使用者提供檔名時，依序在下列位置尋找該檔案：

1. `G:\我的雲端硬碟\Claude共用\`
2. 「掃帶歐印萬」資料夾（不是名稱含 `v2` 的資料夾）

在「掃帶歐印萬」資料夾查找時，以素材 TC 起始時間的六位數作為檔名線索。例如 TC 從 `00:12:34` 開始，檔名線索為 `001234`。

使用者也可能不提供要引用的句子，而是將完整、未經處理的外電原始文稿（例如 Reuters 完整逐字稿或 shotlist 原文）直接貼在文字視窗，要求自行挑選。此時直接以使用者貼上的原文判斷，不另行尋找素材檔案查看內容。

## 2. 決定要掐的引言

- 使用者有提供原句或大致內容時，以該內容作為比對目標。
- 使用者要求自行挑選時，從其貼上的原始文稿中選擇一段具有新聞價值且有衝突性的 Bite。
- 不擴寫或改寫英文引言；最後輸出的英文必須逐字照抄來源原文。

## 3. 對照逐字稿找 TC

以選定引言對照該素材的逐字稿／transcript，找出 Bite 的起訖 TC。

- 若使用者貼上的原始文稿本身已有時間標記，直接使用該標記。
- 若原始文稿沒有時間標記，才查找既有素材所附的逐字稿／transcript 來確認。
- 逐字稿標示的時間精確度就是可用上限，不自行推估到更細的時間，也不宣稱比逐字稿更精確。
- TC 一律顯示為 `HH:MM:SS - HH:MM:SS`。

## 4. 直接輸出結果

只在對話中貼出以下文字，不另存檔、不剪片、不上傳：

```text
SB：{中文職稱} {英文姓名}
{中文翻譯}
TC：00:00:23 - 00:00:31
“{英文原文逐字}”
```

格式規則：

- 順序固定為：SB → 中文翻譯 → TC → 英文原文。
- SB 固定寫成「中文職稱 英文姓名」，不加括號，不加中文姓名音譯。
- 中文翻譯必須是忠於原意的原創繁體中文翻譯。
- 英文逐字照抄來源原文，並保留引號；若來源未附引號，輸出時以引號框住整段引言。
- 除上述四項內容外，不附加流程說明、搜尋紀錄或檔案處理說明。
